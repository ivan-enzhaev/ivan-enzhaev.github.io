Build and Run for Windows (MinGW) Сборка и запуск для Windows (MinGW)

Make sure you have set up your environment and built the required libraries for Windows (MinGW) by following these instructions: Убедитесь, что вы настроили окружение и собрали необходимые библиотеки для Windows (MinGW), следуя этим инструкциям:
  • C/C++ Development Environment Setup for Windows (MinGW, CMake & IDEs) Настройка среды разработки C/C++ для Windows (MinGW, CMake и IDE)
  • Building SDL3 Static Library for Windows (MinGW & CMake) Сборка статической библиотеки SDL3 для Windows (MinGW и CMake)

Configure the project: Сконфигурируйте проект: 

config-exe

Build the project: Соберите проект: 

build-exe

Run the project: Запустите проект: 

run-exe

Build and Run for Android Сборка и запуск для Android

Make sure you have set up your environment and built the required shared libraries for Android by following these instructions: Убедитесь, что вы настроили окружение и собрали необходимые динамические библиотеки для Android, следуя этим инструкциям:
  • Android Environment Setup Настройка окружения Android
  • Building SDL3 Shared Library for Android (NDK & CMake) Сборка динамической библиотеки SDL3 для Android (NDK и CMake)

Build the project: Соберите проект: 

build-apk

Install the app to the device: Установите приложение на устройство: 

install-apk

Build and Run for WebAssembly Сборка и запуск для WebAssembly

Make sure you have set up your environment and built the required static libraries for WebAssembly by following these instructions: Убедитесь, что вы настроили окружение и собрали необходимые статические библиотеки для WebAssembly, следуя этим инструкциям:
  • C/C++ Development Environment Setup for Windows (MinGW, CMake & IDEs) Настройка среды разработки C/C++ для Windows (MinGW, CMake и IDE)
  • Building SDL3 Static Library for WebAssembly (Emscripten & CMake) Сборка статической библиотеки SDL3 для WebAssembly (Emscripten и CMake)

Configure the project: Сконфигурируйте проект: 

config-wasm

Build the project: Соберите проект: 

build-wasm

Now, start your local server: Теперь запустите локальный сервер: 

# Option 1: Using Node.js (http-server)
http-server -c-1

# Option 2: Using Python
python -m http.server 8080
Open localhost:8080 in your browser and check the console (F12 or Ctrl+Shift+J) to see the output. Откройте localhost:8080 в браузере и проверьте консоль (F12 или Ctrl+Shift+J), чтобы увидеть результат.
