Qt 6 + cgltf + cglm + SDL3_image (WebP) + Modern OpenGL 3.3 Core: Rotating 3D Textured Model Y-Bot (Desktop) Qt 6 + cgltf + cglm + SDL3_image (WebP) + Modern OpenGL 3.3 Core: Вращающаяся 3D-текстурированная модель Y-Bot (Desktop)

A step-by-step guide to configuring and running a static desktop project integrating Qt 6, the cgltf library for parsing glTF binary (.glb) files, cglm math library for Perspective, View, and Model (MVP) transformations, depth testing, SDL3_image with WebP, and smooth 90°/s rotation around the Y-axis via QTimer on Windows and Ubuntu. Пошаговое руководство по настройке и запуску статического десктопного проекта, объединяющего Qt 6, библиотеку cgltf для парсинга бинарных файлов glTF (.glb), математическую библиотеку cglm для перспективных, видовых и модельных (MVP) преобразований, тест глубины, SDL3_image с поддержкой WebP и плавное вращение вокруг оси Y со скоростью 90°/с через QTimer под Windows и Ubuntu.

2. Project Directory Structure 2. Структура каталогов проекта

The repository contains the following files: Репозиторий содержит следующие файлы: 

textured-y-bot-cgltf-cglm-sdl3-image-webp-qt6-desktop/
├── assets/
│   └── models/
│       └── y-bot/
│           ├── y-bot.glb
│           └── y-bot.webp
├── src/
│   ├── main.cpp
│   ├── mainwindow.h
│   └── mainwindow.cpp
└── CMakeLists.txt
  • assets/models/y-bot/y-bot.glb: The binary glTF 2.0 3D model parsed at runtime using the lightweight, single-header cgltf library to extract vertex positions, normals, texture coordinates, and index buffers.Бинарная 3D-модель формата glTF 2.0, загружаемая во время выполнения с помощью легковесной single-header библиотеки cgltf для извлечения позиций вершин, нормалей, текстурных координат и буферов индексов.
  • assets/models/y-bot/y-bot.webp: The WebP diffuse texture loaded at runtime via SDL3_image and bound to a 2D OpenGL texture sampler.Диффузная текстура формата WebP, загружаемая во время выполнения через SDL3_image и привязываемая к 2D-сэмплеру текстуры OpenGL.
  • src/mainwindow.h / src/mainwindow.cpp: Subclasses QOpenGLWidget, initializes GLAD, parses the GLB mesh using cgltf, sets up VAO/VBOs/EBO for model geometry, enables GL_DEPTH_TEST, calculates Model, View, and Perspective matrices using cglm, rotates the model around the Y-axis at 90°/s via QTimer and QElapsedTimer, and passes the combined MVP matrix to the vertex shader uniform u_mvp.Наследует QOpenGLWidget, инициализирует GLAD, парсит меш GLB с помощью cgltf, настраивает VAO/VBO/EBO для геометрии модели, включает GL_DEPTH_TEST, вычисляет матрицы модели, вида и перспективы с помощью cglm, вращает модель вокруг оси Y со скоростью 90°/с с помощью QTimer и QElapsedTimer и передаёт результирующую MVP-матрицу в uniform-переменную вершинного шейдера u_mvp.
  • src/main.cpp: Initializes SDL3, sets the OpenGL 3.3 Core profile format with a 24-bit depth buffer (format.setDepthBufferSize(24)), and starts the Qt application event loop.Инициализирует SDL3, задаёт профиль OpenGL 3.3 Core с 24-битным буфером глубины (format.setDepthBufferSize(24)) и запускает цикл событий приложения Qt.
  • CMakeLists.txt: Configures include directories for cgltf (C:/libs/cgltf-1.15 on Windows or $ENV{HOME}/libs/cgltf-1.15 on Linux) and cglm (C:/libs/cglm-0.9.6/include), and sets up static linking for Qt 6, GLAD, SDL3, SDL3_image, and libwebp.Настраивает каталоги включения для cgltf (C:/libs/cgltf-1.15 на Windows или $ENV{HOME}/libs/cgltf-1.15 на Linux) и cglm (C:/libs/cglm-0.9.6/include), а также задаёт статическую компоновку с Qt 6, GLAD, SDL3, SDL3_image и libwebp.
3D Model Asset: The 3D model was downloaded from Mixamo, and an optimized low-poly version was created with Blender and exported to y-bot.glb and y-bot.webp. 3D-модель: 3D-модель была загружена с Mixamo, а оптимизированная low-poly версия создана в Blender и экспортирована в форматы y-bot.glb и y-bot.webp.

3. Project Configuration & Testing in Qt Creator (Windows) 3. Конфигурация проекта и запуск в Qt Creator (Windows)

How to Open and Run in Qt Creator: Как открыть и запустить проект в Qt Creator:

  1. In Qt Creator, click File > Open File or Project... (or press Ctrl+O). В Qt Creator нажмите File > Open File or Project... (или нажмите Ctrl+O).
  2. Navigate to the cloned repository folder and select the CMakeLists.txt file. Перейдите в папку склонированного репозитория и выберите файл CMakeLists.txt.
  3. In the Configure Project screen, select your kit Qt 6.12.0 Static (MinGW 16.2).
    Important: Only Debug is checked by default. Make sure to also check the Release checkbox so that Qt Creator configures the optimized release build! Then click Configure Project.     На экране Configure Project выберите ваш Kit Qt 6.12.0 Static (MinGW 16.2).
    Важно: По умолчанию галочка стоит только на Debug. Обязательно поставьте галочку напротив Release, чтобы Qt Creator сконфигурировал оптимизированную Release-сборку! После этого нажмите Configure Project.
  4. Switch the active build configuration to Release (click the monitor icon in the bottom-left corner of Qt Creator or press Ctrl+T). Переключите активную конфигурацию сборки на Release (нажмите на значок монитора в левом нижнем углу окна Qt Creator или нажмите Ctrl+T).
  5. Press Ctrl+R to build and launch! The resulting single executable in the release build folder will run smoothly without needing any external DLLs. Нажмите Ctrl+R для сборки и запуска! Итоговый одиночный .exe файл в папке release-сборки запустится плавно без необходимости наличия каких-либо внешних DLL.

4. Build and Run on Ubuntu & Ubuntu WSL (Terminal) 4. Сборка и запуск на Ubuntu и Ubuntu WSL (Терминал)

On Ubuntu or Ubuntu WSL, configure and compile the project using CMake and Ninja from the terminal: В Ubuntu или Ubuntu WSL сконфигурируйте и скомпилируйте проект с помощью CMake и Ninja через терминал: 

wsl -d Ubuntu

mkdir dist && cd dist

# Configure pointing to your static Qt
cmake -DCMAKE_PREFIX_PATH=$HOME/libs/qt-6.12.0-static-gcc \
      -DCMAKE_BUILD_TYPE=Release \
      -GNinja ..

# Build
ninja

# Run! Window appears seamlessly on Windows desktop via WSLg
./app

5. Expected Output 5. Ожидаемый результат

When launched, the desktop application displays a 500x500 window showing the textured 3D Y-Bot character model rotating smoothly around the Y-axis at exactly 90 degrees per second. Depth testing ensures rear geometry is properly occluded, and perspective projection creates realistic spatial depth with no lighting applied. При запуске откроется нативное десктопное окно (500x500), отображающее текстурированную 3D-модель персонажа Y-Bot, плавно вращающуюся вокруг оси Y со скоростью ровно 90 градусов в секунду. Буфер глубины корректно отсекает скрытую геометрию, а перспективная проекция создаёт реалистичный объём без использования освещения.
