Integrating Dear ImGui with SDL3 (Cross-Platform: Desktop, Android & Wasm) Интеграция Dear ImGui с SDL3 (Кроссплатформенный пример: Desktop, Android и Wasm)

Build and run a unified Dear ImGui and SDL3 application across desktop platforms (Windows MinGW, Ubuntu Linux), mobile devices (Android GLES3), and the web (WebAssembly / WebGL2) using one general codebase. Сборка и запуск единого приложения Dear ImGui и SDL3 на десктопных платформах (Windows MinGW, Ubuntu Linux), мобильных устройствах (Android GLES3) и в вебе (WebAssembly / WebGL2) из общего репозитория.

🚀 Live WebAssembly Demo 🚀 Онлайн-демо в WebAssembly

Test this cross-platform Dear ImGui + SDL3 project directly in your browser before compiling locally: Попробуйте этот кроссплатформенный проект Dear ImGui + SDL3 прямо в браузере перед локальной сборкой:

Open Live Wasm Demo → Открыть Онлайн Wasm Демо →

Step 1: Download the Unified Cross-Platform Project from GitHub Шаг 1: Скачивание общего кроссплатформенного проекта с GitHub

Clone the general cross-platform repository or download the source archive: Клонируйте общий кроссплатформенный репозиторий или скачайте архив с исходным кодом: 

git clone https://github.com/ivan-enzhaev/imgui-sdl3-opengl-cross-platform.git
cd imgui-sdl3-opengl-cross-platform

GitHub repository: https://github.com/ivan-enzhaev/imgui-sdl3-opengl-cross-platform Репозиторий на GitHub: https://github.com/ivan-enzhaev/imgui-sdl3-opengl-cross-platform

This single repository contains the unified C++ code with modern SDL3 Callbacks API (SDL_AppInit, SDL_AppIterate, SDL_AppEvent, SDL_AppQuit) and ready-to-use build scripts for all targets. Этот репозиторий содержит единый исходный код C++ на современном SDL3 Callbacks API (SDL_AppInit, SDL_AppIterate, SDL_AppEvent, SDL_AppQuit) и готовые скрипты сборки под все платформы.

Building for Windows (MinGW, OpenGL 3.3) Сборка под Windows (MinGW, OpenGL 3.3)

Make sure you have completed the prerequisite setups for Windows: Убедитесь, что вы предварительно настроили среду для Windows:
  • Windows (MinGW, CMake & Ninja) Setup Guide Руководство по настройке Windows (MinGW, CMake и Ninja)
  • Building SDL3 Static Library for Windows Сборка статической библиотеки SDL3 для Windows
  • Installing GLAD OpenGL Loader Library on Windows & Ubuntu (OpenGL 3.3) Установка библиотеки-загрузчика OpenGL GLAD под Windows и Ubuntu (OpenGL 3.3)
  • Installing Dear ImGui Library on Windows & Ubuntu (OpenGL 3.3) Установка библиотеки Dear ImGui под Windows и Ubuntu (OpenGL 3.3)
  • Integrating Dear ImGui with SDL3 on Windows & Ubuntu (OpenGL 3.3) Интеграция Dear ImGui с SDL3 под Windows и Ubuntu (OpenGL 3.3)

Open Command Prompt or PowerShell in the project root directory and run: Откройте командную строку (CMD) или PowerShell в корне проекта и запустите: 

config-win
build-win
run-win

Building for Ubuntu Linux (OpenGL 3.3) Сборка под Ubuntu Linux (OpenGL 3.3)

Make sure you have completed the prerequisite setups for Ubuntu: Убедитесь, что вы предварительно настроили среду для Ubuntu:
  • Ubuntu C/C++ Development Environment Setup Guide Руководство по настройке среды разработки C/C++ на Ubuntu
  • Building SDL3 Static Library for Ubuntu Сборка статической библиотеки SDL3 для Ubuntu
  • Installing GLAD OpenGL Loader Library on Windows & Ubuntu (OpenGL 3.3) Установка библиотеки-загрузчика OpenGL GLAD под Windows и Ubuntu (OpenGL 3.3)
  • Installing Dear ImGui Library on Windows & Ubuntu (OpenGL 3.3) Установка библиотеки Dear ImGui под Windows и Ubuntu (OpenGL 3.3)
  • Integrating Dear ImGui with SDL3 on Windows & Ubuntu (OpenGL 3.3) Интеграция Dear ImGui с SDL3 под Windows и Ubuntu (OpenGL 3.3)

In your terminal, grant execution permissions and run the build scripts: В терминале предоставьте права на выполнение и запустите скрипты сборки: 

chmod +x config-linux.sh build-linux.sh run-linux.sh
./config-linux.sh
./build-linux.sh
./run-linux.sh

Make sure you have configured the Android toolchain and SDL3 Android shared library: Убедитесь, что вы настроили инструменты Android и динамическую библиотеку SDL3 для Android:
  • MinGW & CMake Setup Guide Руководство по настройке MinGW и CMake
  • Android Environment Setup Guide (SDK, NDK, JDK) Руководство по настройке окружения Android (SDK, NDK, JDK)

  • Integrating compiled libSDL3.so on Android (OpenGL ES 3.0) Интеграция собранной библиотеки libSDL3.so на Android (OpenGL ES 3.0)

On Windows: connect your Android device with USB debugging enabled and run: На Windows: подключите Android-устройство с включенной отладкой по USB и запустите: 

build-android
install-android

Make sure you have configured Emscripten and the SDL3 Wasm static library: Убедитесь, что вы настроили Emscripten и статическую библиотеку SDL3 для Wasm:
  • MinGW & CMake Setup Guide Руководство по настройке MinGW и CMake
  • Emscripten & CMake Setup Guide Руководство по настройке Emscripten и CMake
  • Building SDL3 Static Library for WebAssembly (Emscripten & CMake) Сборка статической библиотеки SDL3 для WebAssembly (Emscripten и CMake)
  • Installing Dear ImGui Library (OpenGL) for WebAssembly (Emscripten & CMake) Установка библиотеки Dear ImGui (OpenGL) для WebAssembly (Emscripten и CMake)
  • Integrating Dear ImGui with SDL3 on WebAssembly (OpenGL ES 3.0 / WebGL 2.0) Интеграция Dear ImGui с SDL3 в WebAssembly (OpenGL ES 3.0 / WebGL 2.0)

On Windows: run the web configuration and build scripts: На Windows: запустите скрипты конфигурации и сборки под веб: 

config-web
build-web

Start a local HTTP server to preview in your browser: Запустите локальный HTTP-сервер для просмотра в браузере: 

python -m http.server -d public
# or
npx http-server public -c-1
