Rotating 3D Textured Y-Bot with cgltf, cglm, SDL3_image & OpenGL (Cross-Platform: Desktop, Android & Wasm) Вращающийся текстурированный 3D Y-Bot с помощью cgltf, cglm, SDL3_image и OpenGL (Кроссплатформенный пример: Desktop, Android и Wasm)

Build and run a unified 3D Y-Bot model rendering application using cgltf for fast binary GLB parsing, cglm for MVP matrix math, and SDL3_image for WebP texture loading across desktop platforms (Windows MinGW, Ubuntu Linux), mobile devices (Android GLES3), and the web (WebAssembly / WebGL2) from a single C++ codebase. Сборка и запуск единого приложения для отрисовки 3D модели Y-Bot с использованием cgltf для парсинга бинарных файлов GLB, cglm для матричных расчетов (MVP) и SDL3_image для загрузки WebP текстур на десктопных платформах (Windows MinGW, Ubuntu Linux), мобильных устройствах (Android GLES3) и в вебе (WebAssembly / WebGL2) из общего репозитория на C++.

3D Model Asset: The 3D model was downloaded from Mixamo, and an optimized low-poly version was created with Blender and exported to y-bot.glb and y-bot.webp. 3D-модель: 3D-модель была загружена с Mixamo, а оптимизированная low-poly версия создана в Blender и экспортирована в форматы y-bot.glb и y-bot.webp.

Step 1: Download the Unified Cross-Platform Project from GitHub Шаг 1: Скачивание общего кроссплатформенного проекта с GitHub

Clone the general cross-platform repository or download the source archive: Клонируйте общий кроссплатформенный репозиторий или скачайте архив с исходным кодом: 

git clone https://github.com/ivan-enzhaev/textured-y-bot-cgltf-cglm-sdl3-image-webp-opengl-sdl3-cpp.git
cd textured-y-bot-cgltf-cglm-sdl3-image-webp-opengl-sdl3-cpp

GitHub repository: https://github.com/ivan-enzhaev/textured-y-bot-cgltf-cglm-sdl3-image-webp-opengl-sdl3-cpp Репозиторий на GitHub: https://github.com/ivan-enzhaev/textured-y-bot-cgltf-cglm-sdl3-image-webp-opengl-sdl3-cpp

This repository contains a unified C++20 codebase using modern SDL3 Callbacks (SDL_AppInit, SDL_AppIterate, SDL_AppEvent, SDL_AppQuit), fast glTF/GLB loading via single-header cgltf, hardware depth testing, 3D math powered by the cglm library, automatic WebGL canvas resizing without blinking, unified shader sources, and build scripts for all targets. Этот репозиторий содержит единый исходный код на C++20 с использованием современного SDL3 Callbacks API (SDL_AppInit, SDL_AppIterate, SDL_AppEvent, SDL_AppQuit), быстрой загрузки glTF/GLB через single-header библиотеку cgltf, аппаратного буфера глубины (Z-buffer), 3D математики на базе библиотеки cglm, плавного ресайза канваса WebGL без мерцания, общих шейдеров и готовых скриптов сборки под все платформы.
