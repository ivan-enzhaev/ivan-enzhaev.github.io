FPS Controller with Animated Y-Bots (Box3D, Recast, BT.CPP, ozz-animation & SDL3) FPS контроллер с анимированными Y-Bot (Box3D, Recast, BT.CPP, ozz-animation и SDL3)

A complete multiplatform starter guide featuring a First-Person capsule controller, animated follower Y-Bot robots with 4-layer blend trees, Box3D 3D physics, Detour Crowd pathfinding, BehaviorTree.CPP logic, and dual mobile touch controls for Windows, Ubuntu, Android, and WebAssembly (Emscripten). Полное мультиплатформенное руководство по стартовому проекту с FPS-контроллером игрока, анимированными роботами Y-Bot с 4-слойным блендингом, 3D-физикой Box3D, навигацией толпы Detour Crowd, логикой BehaviorTree.CPP и мобильным сенсорным управлением для Windows, Ubuntu, Android и WebAssembly (Emscripten).

Step 3: Setup & Build by Platform Шаг 3: Настройка и сборка по платформам

Platform 1: Windows (MinGW & CMake) Платформа 1: Windows (MinGW и CMake)

Extract the downloaded archive to C:\projects\fps-ybots-follow-box3d-sdl3. Run the preconfigured batch scripts in Command Prompt: Распакуйте архив в C:\projects\fps-ybots-follow-box3d-sdl3. Запустите готовые пакетные файлы в командной строке: 

cd C:\projects\fps-ybots-follow-box3d-sdl3

config-exe.bat
build-exe.bat
run-exe.bat
Note: The executable statically links SDL3, Box3D, Recast, and BehaviorTree.CPP. The assets directory is automatically copied into the output folder. Примечание: Исполняемый файл статически линкует SDL3, Box3D, Recast и BehaviorTree.CPP. Директория assets автоматически копируется в папку сборки.
Platform 2: Ubuntu Linux (GCC / Clang & Ninja) Платформа 2: Ubuntu Linux (GCC / Clang и Ninja)

Download and extract the repository in your terminal, make the scripts executable, and build: Скачайте и распакуйте репозиторий в терминале, сделайте скрипты исполняемыми и соберите проект: 

mkdir -p ~/projects && cd ~/projects
wget https://github.com/ivan-enzhaev/fps-ybots-follow-box3d-sdl3/archive/refs/heads/main.zip -O fps-ybots-follow-box3d-sdl3.zip
unzip -o fps-ybots-follow-box3d-sdl3.zip
mv fps-ybots-follow-box3d-sdl3-main fps-ybots-follow-box3d-sdl3
cd fps-ybots-follow-box3d-sdl3

chmod +x config-bin.sh build-bin.sh run-bin.sh
./config-bin.sh
./build-bin.sh
./run-bin.sh
Platform 3: Android (Android NDK & CMake) Платформа 3: Android (Android NDK и CMake)

The Android build produces an arm64-v8a shared library and packages it into an APK using the SDL3 Android Java wrapper. Assets are bundled directly into the APK's asset manager: Сборка для Android компилирует библиотеку .so для arm64-v8a и упаковывает её в APK через обертку SDL3. Все ресурсы автоматически включаются в ассеты APK: 

# Configure and compile native arm64-v8a shared libraries & APK
config-apk.bat
build-apk.bat

# Install to connected Android device or emulator via ADB
install-apk.bat
OpenGL ES 3.0 is automatically used. The dual-zone virtual joystick and on-screen jump button appear automatically on Android touchscreens. Автоматически используется OpenGL ES 3.0. Двухзонный виртуальный джойстик и экранная кнопка прыжка активны по умолчанию на сенсорных экранах Android.
Platform 4: WebAssembly (Emscripten & WebGL 2.0) Платформа 4: WebAssembly (Emscripten и WebGL 2.0)

Compile to WebAssembly using the Emscripten SDK (emcmake). Assets are packed using --embed-file assets@/assets: Скомпилируйте проект в WebAssembly с помощью Emscripten SDK (emcmake). Ресурсы упаковываются с ключом --embed-file assets@/assets: 

# Activate Emscripten environment
call C:\emsdk\emsdk_env.bat

# Configure and compile WASM build
config-wasm.bat
build-wasm.bat

# Start local server and open in browser
run-wasm.bat
The mouse cursor arrow remains visible when loading. Click into the canvas to engage first-person pointer lock; press ESC once to release the cursor. Курсор мыши виден при первой загрузке. Кликните в область игры для захвата мыши; нажмите ESC один раз для освобождения курсора.
