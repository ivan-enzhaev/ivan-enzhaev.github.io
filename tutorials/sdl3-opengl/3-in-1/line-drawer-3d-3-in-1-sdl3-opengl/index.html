Line drawer in 3D Рисование линии в 3D

Drawing a line in 3D for Windows, Android, and WebAssembly. Рисование линии в 3D для Windows, Android, и WebAssembly.

View the Wasm Demo in the Browser Запустить Wasm-демо в браузере

Source Code Исходный код

You can explore the source code and download the complete project directly from the GitHub repository: Вы можете изучить исходный код и скачать готовый проект напрямую из репозитория на GitHub:

C Version: View C Repo Репозиторий (C)
C++ Version: View C++ Repo Репозиторий (C++)

Obtain tools: Получение инструментов:

  • Desktop (Windows): Setting up SDL3 with find_package (MinGW) Desktop (Windows): Настройка SDL3 с помощью find_package (MinGW)
  • Android: Setting up a template project Android: Настройка шаблонного проекта
  • WebAssembly: Building SDL3 for WebAssembly WebAssembly Сборка SDL3 для WebAssembly

Build and Run for Windows (MinGW) Сборка и запуск для Windows (MinGW)

Configure the project: Сконфигурируйте проект: 

config-exe

Build the project: Соберите проект: 

build-exe

Run the project: Запустите проект: 

run-exe

Build and Run for Android Сборка и запуск для Android

Build the project: Соберите проект: 

build-apk

Install the app to the device: Установите приложение на устройство: 

install-apk

Useful Tips Полезные советы

  • Show a log: adb logcat -s SDL Показать лог: adb logcat -s SDL
  • Clear a log: adb logcat -c Очистить лог: adb logcat -c
  • Check connected devices: adb devices Проверка подключенных устройств: adb devices
  • Use scrcpy to mirror your phone screen to your PC via USB. Используйте scrcpy для трансляции экрана телефона на ПК через USB.

Build and Run for WebAssembly Сборка и запуск для WebAssembly

Configure the project: Сконфигурируйте проект: 

config-wasm

Build the project: Соберите проект: 

build-wasm

Now, start your local server: Теперь запустите локальный сервер: 

# Option 1: Using Node.js (http-server)
http-server -c-1

# Option 2: Using Python
python -m http.server 8080
Open localhost:8080 in your browser and check the console (F12 or Ctrl+Shift+J) to see the output. Откройте localhost:8080 в браузере и проверьте консоль (F12 или Ctrl+Shift+J), чтобы увидеть результат.
