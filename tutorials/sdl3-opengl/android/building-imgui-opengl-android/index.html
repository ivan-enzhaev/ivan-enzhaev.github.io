Building ImGui from source for SDL3 and OpenGL (MinGW and CMake) Сборка Настройка ImGui для SDL3 и OpenGL (MinGW and CMake)

Prerequisite: Ensure you have followed the Environment Setup Guide (MinGW & CMake) Предварительное условие: Убедитесь, что вы выполнили инструкции из руководства по настройке среды (MinGW и CMake)

Download the source code archives: Скачайте архивы с исходным кодом:

  • Go to the Dear ImGui Releases page, scroll down to the bottom, and download Source code (zip). Перейдите на страницу Dear ImGui Releases, прокрутите страницу вниз и скачайте Source code (zip).
  • Extract into the C:\libs folder Распакуйте в папку C:\libs

Create a folder: C:\libs\imgui-1.92.9-mingw. Inside it, create four empty subfolders: Создайте папку: C:\libs\imgui-1.92.9-mingw. Внутри неё создайте четыре пустые подпапки:

  • dist
  • include
  • lib
  • src_to_build
  • src

Prepare the Dear ImGui folder structure: Подготовьте структуру папок для Dear ImGui:

  • Open the extracted imgui-1.92.9 folder and copy the following .cpp files from the root: imgui.cpp, imgui_draw.cpp, imgui_tables.cpp, imgui_widgets.cpp. Paste them into С:\libs\imgui-1.92.9-mingw\src_to_build. Откройте распакованную папку imgui-1.92.9 и скопируйте следующие файлы .cpp из корня: imgui.cpp, imgui_draw.cpp, imgui_tables.cpp, imgui_widgets.cpp. Вставьте их в С:\libs\imgui-1.92.9-mingw\src_to_build.
  • Copy all .h files from the root of imgui-1.92.8 (imconfig.h, imgui.h, imgui_internal.h, etc.) and paste them into E:\libs\imgui-1.92.8-mingw\include. Скопируйте все файлы .h из корня imgui-1.92.8 (imconfig.h, imgui.h, imgui_internal.h и т.д.) и вставьте их в E:\libs\imgui-1.92.8-mingw\include.
  • Open imgui-1.92.9\backends. Copy the following headers: imgui_impl_sdl3.h, imgui_impl_opengl3.h, imgui_impl_opengl3_loader.h) into the С:\libs\imgui-1.92.9-mingw\include folder, and copy the source files (imgui_impl_sdl3.cpp, imgui_impl_opengl3.cpp) into the С:\libs\imgui-1.92.9-mingw\src folder. Откройте imgui-1.92.9\backends. Скопируйте следующие заголовочные файлы (imgui_impl_sdl3.h, imgui_impl_opengl3.h, imgui_impl_opengl3_loader.h) в папку С:\libs\imgui-1.92.9-mingw\include, а исходники (imgui_impl_sdl3.cpp, imgui_impl_opengl3.cpp) — в папку С:\libs\imgui-1.92.9-mingw\src.

Create a CMakeLists.txt file inside the dist folder: Создайте файл CMakeLists.txt внутри папки dist: 

cmake_minimum_required(VERSION 3.21)
project(imgui_static)

set(IMGUI_PATH_INCLUDE "${CMAKE_CURRENT_SOURCE_DIR}/../include")
set(IMGUI_PATH_SRC "${CMAKE_CURRENT_SOURCE_DIR}/../src_to_build")

file(GLOB IMGUI_SOURCES "${IMGUI_PATH_SRC}/*.cpp")

add_library("ImGui" STATIC ${IMGUI_SOURCES})
target_include_directories("ImGui" PUBLIC ${IMGUI_PATH_INCLUDE})
# Link SDL3 header paths here if required by backends
target_include_directories("ImGui" PRIVATE "C:/libs/SDL3-devel-3.4.12-mingw/include")

# Explicitly copy libImGui.a to the sibling ../lib folder after building
add_custom_command(TARGET "ImGui" POST_BUILD
    COMMAND ${CMAKE_COMMAND} -E make_directory "${CMAKE_CURRENT_SOURCE_DIR}/../lib"
    COMMAND ${CMAKE_COMMAND} -E copy
        $
        "${CMAKE_CURRENT_SOURCE_DIR}/../lib/"
    COMMENT "Copying libImGui.a to ../lib folder"
)

Create a build-android.bat file inside the dist folder: Создайте файл build-android.bat внутри папки dist: 

@echo off
set NDK=H:/AndroidSDK/ndk/27.0.12077973

:: Create an Android-specific build and output structure
if not exist build-android-arm64 mkdir build-android-arm64
cd build-android-arm64

cmake .. ^
  -DCMAKE_TOOLCHAIN_FILE="%NDK%/build/cmake/android.toolchain.cmake" ^
  -DANDROID_ABI=arm64-v8a ^
  -DANDROID_PLATFORM=android-28 ^
  -DCMAKE_BUILD_TYPE=Release ^
  -G "Ninja"

cmake --build . --config Release

cd ..

Compile Dear ImGui using MinGW via Command Prompt (CMD): Скомпилируйте Dear ImGui с помощью MinGW через командную строку (CMD):

  • Open CMD inside of the С:\libs\imgui-1.92.9-mingw\dist folder Откройте CMD в папке С:\libs\imgui-1.92.9-mingw\dist
  • Generate MinGW Makefiles: Сгенерируйте MinGW Makefiles: 
    cmake -G "MinGW Makefiles" .
  • Build the static library (libImGui.a will be generated in the lib folder): Соберите статическую библиотеку (libImGui.a будет создана в папке lib): 
    mingw32-make

Delete the dist and src_to_build folders Удалите папки dist и src_to_build

Library Folder Structure Структура папок библиотек

To manage the plotting and UI ecosystem, ensure your C:/libs directory has the following layout for ImGui and ImPlot: Для работы с экосистемой графиков и интерфейса убедитесь, что в вашей директории C:/libs подготовлена следующая структура для ImGui и ImPlot: 

C:/libs/
└── imgui-1.92.6-mingw/
    ├── include/ (imgui.h, imconfig.h, etc.)
    ├── lib/ (libImGui.a)
    └── src/
        ├── imgui_impl_opengl3.cpp
        └── imgui_impl_sdl3.cpp
