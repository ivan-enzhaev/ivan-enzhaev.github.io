Integrating Dear ImGui with SDL3 on Android (OpenGL ES 3.0) Интеграция Dear ImGui с SDL3 на Android (OpenGL ES 3.0)

A step-by-step guide to integrating Dear ImGui source files with SDL3 and OpenGL ES 3.0 on Android, setting up touch scaling, building the APK with Gradle, and running it on a device. Пошаговое руководство по интеграции исходных файлов Dear ImGui с SDL3 и OpenGL ES 3.0 на Android, настройке масштабирования под сенсорный ввод, сборке APK с помощью Gradle и запуску на устройстве.

Before proceeding, make sure you have configured your MinGW and Android NDK build environment on Windows using the following guides: Перед продолжением убедитесь, что вы настроили рабочее окружение MinGW и Android NDK в Windows, следуя соответствующим инструкциям:
  • MinGW & CMake Setup Guide Руководство по настройке MinGW и CMake
  • Android Environment Setup Guide (SDK, NDK, JDK) Руководство по настройке окружения Android (SDK, NDK, JDK)
This guide builds on the starter project created in: Это руководство основано на стартовом проекте, созданном в: Integrating compiled libSDL3.so on Android Интеграция собранной библиотеки libSDL3.so на Android

Ensure you have the Dear ImGui source files available on your machine (e.g. at C:/libs/imgui-1.93.0): Убедитесь, что исходные файлы Dear ImGui доступны на вашем компьютере (например, по пути C:/libs/imgui-1.93.0): 

C:/libs/imgui-1.93.0

Create a project directory named integrate-imgui-android-sdl3-opengl-cpp or copy your existing starter project folder: Создайте директорию проекта с именем integrate-imgui-android-sdl3-opengl-cpp или скопируйте созданную ранее папку стартового проекта:

Step 2: Update CMakeLists.txt Шаг 2: Обновление CMakeLists.txt

In the root of your project folder (next to android-project), update CMakeLists.txt to compile the Dear ImGui sources, define IMGUI_IMPL_OPENGL_ES3, and link with GLESv3: В корне папки вашего проекта (рядом с android-project) обновите CMakeLists.txt для сборки исходных файлов Dear ImGui, добавления макроса IMGUI_IMPL_OPENGL_ES3 и компоновки с GLESv3: 

cmake_minimum_required(VERSION 3.22.1)

project(main CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# Path to Dear ImGui
set(IMGUI_DIR "C:/libs/imgui-1.93.0")

# Locate precompiled SDL3 for Android
find_package(SDL3 REQUIRED CONFIG PATHS "C:/libs/sdl3-3.4.18-android/${ANDROID_ABI}/lib/cmake/SDL3")

# Sources: application code + Dear ImGui core + backends
set(SOURCES
    src/main.cpp
    ${IMGUI_DIR}/imgui.cpp
    ${IMGUI_DIR}/imgui_demo.cpp
    ${IMGUI_DIR}/imgui_draw.cpp
    ${IMGUI_DIR}/imgui_tables.cpp
    ${IMGUI_DIR}/imgui_widgets.cpp
    ${IMGUI_DIR}/backends/imgui_impl_sdl3.cpp
    ${IMGUI_DIR}/backends/imgui_impl_opengl3.cpp
)

# SDLActivity loads libmain.so
add_library(main SHARED ${SOURCES})

# Target include directories
target_include_directories(main PRIVATE
    ${CMAKE_CURRENT_SOURCE_DIR}/src
    ${IMGUI_DIR}
    ${IMGUI_DIR}/backends
)

# Enable GLES3 path inside imgui_impl_opengl3
target_compile_definitions(main PRIVATE
    IMGUI_IMPL_OPENGL_ES3
)

# Link SDL3, OpenGL ES 3.0, EGL, and Android system libraries
target_link_libraries(main PRIVATE
    SDL3::SDL3-shared
    GLESv3
    EGL
    log
    android
)

Step 3: Create the C++ Source File Шаг 3: Создание исходного файла C++

Inside src/main.cpp, initialize the OpenGL ES 3.0 context, set up Dear ImGui with display scale awareness for touch screens, and run the frame loop: В файле src/main.cpp инициализируйте контекст OpenGL ES 3.0, настройте Dear ImGui с учетом масштабирования экрана под сенсорный ввод и запустите цикл отрисовки: 

#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>
#include <GLES3/gl3.h>
#include <android/log.h>

#include "imgui.h"
#include "imgui_impl_sdl3.h"
#include "imgui_impl_opengl3.h"

#define LOG_TAG "ImGui-SDL3-GLES3"
#define LOGI(...) __android_log_print(ANDROID_LOG_INFO, LOG_TAG, __VA_ARGS__)
#define LOGE(...) __android_log_print(ANDROID_LOG_ERROR, LOG_TAG, __VA_ARGS__)

int main(int argc, char* argv[])
{
    // Fix orientation to landscape (optional)
    SDL_SetHint(SDL_HINT_ORIENTATIONS, "LandscapeLeft LandscapeRight");

    // Initialize SDL3 video subsystem
    if (!SDL_Init(SDL_INIT_VIDEO | SDL_INIT_GAMEPAD))
    {
        LOGE("Failed to initialize SDL: %s", SDL_GetError());
        return -1;
    }

    // Configure OpenGL ES 3.0 context attributes
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_FLAGS, 0);
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_PROFILE_MASK, SDL_GL_CONTEXT_PROFILE_ES);
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_MAJOR_VERSION, 3);
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_MINOR_VERSION, 0);
    SDL_GL_SetAttribute(SDL_GL_DOUBLEBUFFER, 1);
    SDL_GL_SetAttribute(SDL_GL_DEPTH_SIZE, 24);
    SDL_GL_SetAttribute(SDL_GL_STENCIL_SIZE, 8);

    // Create SDL window with OpenGL and High-DPI flags
    SDL_WindowFlags window_flags = SDL_WINDOW_OPENGL | SDL_WINDOW_FULLSCREEN | SDL_WINDOW_RESIZABLE | SDL_WINDOW_HIGH_PIXEL_DENSITY;
    SDL_Window* window = SDL_CreateWindow("Dear ImGui SDL3 OpenGL ES 3.0", 0, 0, window_flags);
    if (!window)
    {
        LOGE("Failed to create SDL window: %s", SDL_GetError());
        SDL_Quit();
        return -1;
    }

    // Create OpenGL ES context
    SDL_GLContext gl_context = SDL_GL_CreateContext(window);
    if (!gl_context)
    {
        LOGE("Failed to create OpenGL ES context: %s", SDL_GetError());
        SDL_DestroyWindow(window);
        SDL_Quit();
        return -1;
    }

    SDL_GL_MakeCurrent(window, gl_context);
    SDL_GL_SetSwapInterval(1); // Enable V-Sync

    // Initialize Dear ImGui
    IMGUI_CHECKVERSION();
    ImGui::CreateContext();
    ImGuiIO& io = ImGui::GetIO();
    (void)io;
    io.ConfigFlags |= ImGuiConfigFlags_NavEnableKeyboard;
    io.ConfigFlags |= ImGuiConfigFlags_NavEnableGamepad;
    io.ConfigFlags |= ImGuiConfigFlags_IsTouchScreen;

    // Apply scaling for High-DPI mobile screens
    float scale = SDL_GetDisplayContentScale(SDL_GetDisplayForWindow(window));
    if (scale <= 0.0f)
    {
        scale = 1.0f;
    }
    ImGui::GetStyle().ScaleAllSizes(scale);
    io.FontGlobalScale = scale;

    // Set dark style theme
    ImGui::StyleColorsDark();

    // Initialize platform and OpenGL ES 3.0 renderers
    ImGui_ImplSDL3_InitForOpenGL(window, gl_context);
    const char* glsl_version = "#version 300 es";
    ImGui_ImplOpenGL3_Init(glsl_version);

    // State variables
    bool running = true;
    bool show_demo_window = true;
    ImVec4 clear_color = ImVec4(0.12f, 0.14f, 0.18f, 1.00f);
    int click_counter = 0;

    LOGI("Main loop starting successfully");

    // Main loop
    while (running)
    {
        SDL_Event event;
        while (SDL_PollEvent(&event))
        {
            ImGui_ImplSDL3_ProcessEvent(&event);
            if (event.type == SDL_EVENT_QUIT)
            {
                running = false;
            }
            if (event.type == SDL_EVENT_WINDOW_CLOSE_REQUESTED &&
                event.window.windowID == SDL_GetWindowID(window))
            {
                running = false;
            }
        }

        // Start Dear ImGui frame
        ImGui_ImplOpenGL3_NewFrame();
        ImGui_ImplSDL3_NewFrame();
        ImGui::NewFrame();

        // 1. Show the standard Dear ImGui Demo Window
        if (show_demo_window)
        {
            ImGui::ShowDemoWindow(&show_demo_window);
        }

        // 2. Custom touch-friendly test window
        {
            ImGui::Begin("Dear ImGui with SDL3 & GLES3 on Android");

            ImGui::Text("Application average: %.3f ms/frame (%.1f FPS)",
                        1000.0f / io.Framerate, io.Framerate);
            ImGui::Text("Screen scale factor: %.2f", scale);

            ImGui::Separator();

            ImGui::Checkbox("Show ImGui Demo Window", &show_demo_window);

            // Large touch-friendly button
            if (ImGui::Button("Tap Me!", ImVec2(180 * scale, 60 * scale)))
            {
                click_counter++;
            }
            ImGui::SameLine();
            ImGui::Text("Taps count: %d", click_counter);

            ImGui::Separator();
            ImGui::ColorEdit3("Background Color", (float*)&clear_color);

            ImGui::End();
        }

        // Rendering
        ImGui::Render();

        int display_w, display_h;
        SDL_GetWindowSizeInPixels(window, &display_w, &display_h);
        glViewport(0, 0, display_w, display_h);

        glClearColor(clear_color.x * clear_color.w,
                     clear_color.y * clear_color.w,
                     clear_color.z * clear_color.w,
                     clear_color.w);
        glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT);

        ImGui_ImplOpenGL3_RenderDrawData(ImGui::GetDrawData());
        SDL_GL_SwapWindow(window);
    }

    // Cleanup
    LOGI("Shutting down application");
    ImGui_ImplOpenGL3_Shutdown();
    ImGui_ImplSDL3_Shutdown();
    ImGui::DestroyContext();

    SDL_GL_DestroyContext(gl_context);
    SDL_DestroyWindow(window);
    SDL_Quit();

    return 0;
}

Step 4: Configure Gradle and Android Settings Шаг 4: Настройка Gradle и параметров Android

1. Ensure android-project/app/build.gradle points to your root CMakeLists.txt and targets arm64-v8a (and other desired ABIs): 1. Убедитесь, что android-project/app/build.gradle ссылается на корневой CMakeLists.txt и собирает arm64-v8a (и другие необходимые ABI): 

plugins {
    id 'com.android.application'
}

android {
    namespace "com.example.myapp"
    compileSdk 34

    defaultConfig {
        applicationId "com.example.myapp"
        minSdk 21
        targetSdk 34
        versionCode 1
        versionName "1.0"

        ndk {
            abiFilters 'arm64-v8a'
        }
    }

    buildTypes {
        release {
            minifyEnabled false
            proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
        }
    }

    externalNativeBuild {
        cmake {
            path "../../CMakeLists.txt"
            version "3.22.1"
        }
    }
}

dependencies {
    implementation fileTree(dir: 'libs', include: ['*.jar'])
}

2. Verify the custom Java activity at path android-project/app/src/main/java/com/example/myapp/MyActivity.java loads SDL3 and main libraries: 2. Проверьте, что пользовательский Java-класс по пути android-project/app/src/main/java/com/example/myapp/MyActivity.java загружает библиотеки SDL3 и main: 

package com.example.myapp;

import org.libsdl.app.SDLActivity;

public class MyActivity extends SDLActivity {
    @Override
    protected String[] getLibraries() {
        return new String[] {
            "SDL3",
            "main"
        };
    }
}

3. In android-project/app/src/main/AndroidManifest.xml, verify the activity declaration: 3. В файле android-project/app/src/main/AndroidManifest.xml проверьте объявление activity: 

<activity android:name="com.example.myapp.MyActivity"
    android:label="@string/app_name"
    android:alwaysRetainTaskState="true"
    android:launchMode="singleInstance"
    android:configChanges="orientation|uiMode|screenLayout|screenSize|smallestScreenSize|keyboard|keyboardHidden|navigation"
    android:exported="true">
    <intent-filter>
        <action android:name="android.intent.action.MAIN" />
        <category android:name="android.intent.category.LAUNCHER" />
    </intent-filter>
</activity>

4. Make sure android-project/gradle.properties contains: 4. Убедитесь, что в android-project/gradle.properties указано: 

android.useAndroidX=true

Step 5: Create Build and Install Scripts Шаг 5: Создание скриптов сборки и установки

In the root folder of your project, create the helper batch files to compile and install the application automatically: В корневой папке проекта создайте вспомогательные bat-файлы для автоматической сборки и установки приложения:

build-apk.bat

@echo off
cd android-project
call gradlew.bat assembleDebug
cd ..

install-apk.bat

@echo off
adb install -r android-project\app\build\outputs\apk\debug\app-debug.apk

Step 6: Build, Deploy, and Debug Шаг 6: Сборка, развертывание и отладка

Connect your Android device with USB debugging enabled, then execute the batch scripts in your Command Prompt (CMD): Подключите Android-устройство с включенной отладкой по USB, затем выполните батч-скрипты в командной строке (CMD): 

build-apk
install-apk

Useful ADB Commands: Полезные команды ADB:

Launch the application: Запуск приложения: 

adb shell am start -n com.example.myapp/com.example.myapp.MyActivity

Uninstall the application from the device: Удаление приложения с устройства: 

adb uninstall com.example.myapp

Clear logs and view real-time runtime errors (CMD): Очистка логов и просмотр ошибок в реальном времени (CMD): 

adb logcat -c
for /f %i in ('adb shell pidof -s com.example.myapp') do set APP_PID=%i
adb logcat --pid=%APP_PID%
Tip: Совет: You can open the android-project directory directly in Android Studio to edit code, set breakpoints, and debug with LLDB! Вы можете открыть папку android-project напрямую в Android Studio, чтобы редактировать код, устанавливать точки останова (breakpoints) и отлаживать проект с помощью LLDB!
