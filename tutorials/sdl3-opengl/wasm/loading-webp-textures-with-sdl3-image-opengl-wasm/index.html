Loading WebP Textures with SDL3_image on WebAssembly (WebGL 2.0) Загрузка текстур WebP с помощью SDL3_image в WebAssembly (WebGL 2.0)

A step-by-step guide to compiling SDL3_image with WebP support and WebGL 2.0 into WebAssembly using Emscripten, CMake, virtual filesystem preloading, and running it locally in a web browser. Пошаговое руководство по компиляции библиотеки SDL3_image с поддержкой WebP и WebGL 2.0 в WebAssembly с помощью Emscripten, CMake, предзагрузки файлов в виртуальную файловую систему и запуском в браузере.

Before proceeding, make sure you have configured MinGW, CMake, Emscripten SDK, and built the SDL3 and SDL3_image static libraries using these guides: Перед началом убедитесь, что вы настроили MinGW, CMake, Emscripten SDK и собрали статические библиотеки SDL3 и SDL3_image по этим инструкциям:
  • MinGW & CMake Setup Guide Руководство по настройке MinGW и CMake
  • Emscripten & CMake Setup Guide Руководство по настройке Emscripten и CMake
  • Building SDL3 Static Library for WebAssembly (Emscripten & CMake) Сборка статической библиотеки SDL3 для WebAssembly (Emscripten и CMake)
  • Building SDL3_image Static Library with WebP Support for WebAssembly (Emscripten & CMake) Сборка статической библиотеки SDL3_image с поддержкой WebP для WebAssembly (Emscripten и CMake)
Why SDL3 Callbacks for WebAssembly? Почему функции обратного вызова SDL3 для WebAssembly?

In web browsers, running a traditional infinite while(running) loop blocks the JavaScript main thread and freezes the page. SDL3 solves this natively with its modern Callbacks Architecture (SDL_AppInit, SDL_AppIterate, SDL_AppEvent, SDL_AppQuit). The browser's requestAnimationFrame automatically drives the application rendering at native display refresh rates without extra boilerplate. В браузерах традиционный бесконечный цикл while(running) блокирует основной поток JavaScript и замораживает страницу. В SDL3 эта проблема решена нативно с помощью архитектуры функций обратного вызова (SDL_AppInit, SDL_AppIterate, SDL_AppEvent, SDL_AppQuit). Браузерный requestAnimationFrame сам вызывает шаг отрисовки с частотой обновления экрана без дополнительных надстроек.

Step 4: Configure CMakeLists.txt Шаг 4: Настройка CMakeLists.txt

Create CMakeLists.txt in the project root directory. We configure Emscripten to enable WebGL 2.0 (-sUSE_WEBGL2=1 -sFULL_ES3=1), link the static libSDL3.a, libSDL3_image.a, and WebP libraries, preload the assets directory into the virtual filesystem, and output app.js / app.wasm: Создайте файл CMakeLists.txt в корне проекта. В нём настраивается Emscripten с поддержкой WebGL 2.0 (-sUSE_WEBGL2=1 -sFULL_ES3=1), подключаются статические библиотеки libSDL3.a, libSDL3_image.a и WebP, настраивается предзагрузка папки assets в виртуальную файловую систему, а результатом сборки являются файлы app.js и app.wasm: 

cmake_minimum_required(VERSION 3.21)

if(NOT CMAKE_BUILD_TYPE)
    set(CMAKE_BUILD_TYPE "Debug")
endif()

project(integrate-sdl3-image-webp-wasm CXX)

set(CMAKE_CXX_STANDARD 20)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# -----------------------------------------------------------------------------
# Paths
# -----------------------------------------------------------------------------
set(SDL3_DIR       "C:/libs/sdl3-3.4.18-wasm")
set(SDL3_image_DIR "C:/libs/sdl3_image-3.4.8-webp-wasm")
set(WEBP_DIR       "C:/libs/webp-1.6.0-wasm")

# -----------------------------------------------------------------------------
# Executable Target (Emscripten generates .js and .wasm)
# -----------------------------------------------------------------------------
add_executable(app
    src/main.cpp
)

# Set output name to app.js
set_target_properties(app PROPERTIES
    OUTPUT_NAME "app"
    SUFFIX ".js"
)

# -----------------------------------------------------------------------------
# Include Directories
# -----------------------------------------------------------------------------
target_include_directories(app PRIVATE
    ${CMAKE_CURRENT_SOURCE_DIR}/src
    ${SDL3_DIR}/include
    ${SDL3_image_DIR}/include
    ${WEBP_DIR}/include
)

# -----------------------------------------------------------------------------
# Link Static Libraries
# -----------------------------------------------------------------------------
target_link_libraries(app PRIVATE
    ${SDL3_image_DIR}/lib/libSDL3_image.a
    ${SDL3_DIR}/lib/libSDL3.a
    ${WEBP_DIR}/lib/libwebpdemux.a
    ${WEBP_DIR}/lib/libwebpmux.a
    ${WEBP_DIR}/lib/libwebp.a
    ${WEBP_DIR}/lib/libsharpyuv.a
)

# -----------------------------------------------------------------------------
# Emscripten Link Options (WebGL 2.0, Memory Growth, Preloaded Assets)
# -----------------------------------------------------------------------------
target_link_options(app PRIVATE
    "-sUSE_WEBGL2=1"
    "-sFULL_ES3=1"
    "-sALLOW_MEMORY_GROWTH=1"
    "--preload-file=${CMAKE_CURRENT_SOURCE_DIR}/assets@assets"
)

Step 5: Create Source Code (src/main.cpp) Шаг 5: Создание исходного кода (src/main.cpp)

Create src/main.cpp using the modern SDL3 callbacks architecture. Messages printed with printf are routed straight to browser stdout / console.log() as clean, normal text: Создайте файл src/main.cpp с использованием современной архитектуры callback-функций SDL3. Сообщения, выводимые через printf, направляются напрямую в stdout / console.log() браузера как чистый, обычный текст: 

#define SDL_MAIN_USE_CALLBACKS 1
#include <iostream>
#include <cstdio>
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>
#include <SDL3_image/SDL_image.h>
#include <GLES3/gl3.h>

#ifndef GL_EXT_texture_filter_anisotropic
#define GL_EXT_texture_filter_anisotropic 1
#define GL_TEXTURE_MAX_ANISOTROPY_EXT 0x84FE
#define GL_MAX_TEXTURE_MAX_ANISOTROPY_EXT 0x84FF
#endif

static GLuint createTexture(const char *path)
{
    // Use SDL_IOFromFile to correctly read the file from preloaded virtual filesystem
    SDL_IOStream *io = SDL_IOFromFile(path, "rb");
    if (!io)
    {
        printf("Failed to open file stream for %s: %s\n", path, SDL_GetError());
        return 0;
    }

    // Load the image from the SDL stream
    SDL_Surface *surface = IMG_Load_IO(io, 1); // 1 (true) automatically closes and frees the SDL_IOStream
    if (!surface)
    {
        printf("Image loading failed: %s\n", SDL_GetError());
        return 0;
    }

    // Convert to RGBA / ABGR8888 for WebGL 2.0
    SDL_Surface *optimizedSurface = SDL_ConvertSurface(surface, SDL_PIXELFORMAT_ABGR8888);
    SDL_DestroySurface(surface);

    if (!optimizedSurface)
    {
        printf("Surface conversion failed: %s\n", SDL_GetError());
        return 0;
    }

    GLuint textureID;
    glGenTextures(1, &textureID);
    glBindTexture(GL_TEXTURE_2D, textureID);

    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_CLAMP_TO_EDGE);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_CLAMP_TO_EDGE);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR_MIPMAP_LINEAR);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);

    if (SDL_GL_ExtensionSupported("GL_EXT_texture_filter_anisotropic"))
    {
        float maxAnisotropy = 0.0f;
        glGetFloatv(GL_MAX_TEXTURE_MAX_ANISOTROPY_EXT, &maxAnisotropy);

        // Set the quality to maximum (usually 8.0 or 16.0)
        glTexParameterf(GL_TEXTURE_2D, GL_TEXTURE_MAX_ANISOTROPY_EXT, maxAnisotropy);

        printf("Anisotropic filtering enabled. Max: %.1f\n", maxAnisotropy);
    }
    else
    {
        printf("Anisotropic filtering not supported.\n");
    }

    glPixelStorei(GL_UNPACK_ALIGNMENT, 1);

    glTexImage2D(GL_TEXTURE_2D, 0, GL_RGBA, optimizedSurface->w, optimizedSurface->h,
        0, GL_RGBA, GL_UNSIGNED_BYTE, optimizedSurface->pixels);
    glGenerateMipmap(GL_TEXTURE_2D);

    SDL_DestroySurface(optimizedSurface);

    return textureID;
}

// WebGL 2.0 / OpenGL ES 3.0 Shaders
static const char* vertexShaderSource = R"(#version 300 es
layout (location = 0) in vec2 aPos;
layout (location = 1) in vec2 aTexCoord;

out vec2 TexCoord;

void main() {
    gl_Position = vec4(aPos, 0.0, 1.0);
    TexCoord = aTexCoord;
}
)";

static const char* fragmentShaderSource = R"(#version 300 es
precision mediump float;

out vec4 FragColor;
in vec2 TexCoord;

uniform sampler2D ourTexture;

void main() {
    FragColor = texture(ourTexture, TexCoord);
}
)";

struct AppState {
    SDL_Window* window = nullptr;
    SDL_GLContext gl_context = nullptr;
    GLuint texture = 0;
    GLuint shaderProgram = 0;
    GLuint VAO = 0;
    GLuint VBO = 0;
};

// Called once when the application starts
SDL_AppResult SDL_AppInit(void** appstate, int argc, char* argv[])
{
    (void)argc;
    (void)argv;

    // Initialize SDL3 video subsystem
    if (!SDL_Init(SDL_INIT_VIDEO))
    {
        printf("Failed to initialize SDL: %s\n", SDL_GetError());
        return SDL_APP_FAILURE;
    }

    AppState* state = new AppState();
    *appstate = state;

    // Configure WebGL 2.0 / OpenGL ES 3.0 context attributes
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_FLAGS, 0);
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_PROFILE_MASK, SDL_GL_CONTEXT_PROFILE_ES);
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_MAJOR_VERSION, 3);
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_MINOR_VERSION, 0);
    SDL_GL_SetAttribute(SDL_GL_DOUBLEBUFFER, 1);
    SDL_GL_SetAttribute(SDL_GL_DEPTH_SIZE, 24);
    SDL_GL_SetAttribute(SDL_GL_STENCIL_SIZE, 8);

    // Create SDL window mapped to #canvas
    SDL_WindowFlags window_flags = SDL_WINDOW_OPENGL | SDL_WINDOW_RESIZABLE | SDL_WINDOW_HIGH_PIXEL_DENSITY;
    state->window = SDL_CreateWindow("SDL3_image WebP WebGL2", 1280, 720, window_flags);
    if (!state->window)
    {
        printf("Failed to create SDL window: %s\n", SDL_GetError());
        return SDL_APP_FAILURE;
    }

    // Create WebGL 2.0 context
    state->gl_context = SDL_GL_CreateContext(state->window);
    if (!state->gl_context)
    {
        printf("Failed to create WebGL 2.0 context: %s\n", SDL_GetError());
        return SDL_APP_FAILURE;
    }

    SDL_GL_MakeCurrent(state->window, state->gl_context);
    SDL_GL_SetSwapInterval(1); // Enable V-Sync

    // Shaders & Geometry
    GLuint vertexShader = glCreateShader(GL_VERTEX_SHADER);
    glShaderSource(vertexShader, 1, &vertexShaderSource, NULL);
    glCompileShader(vertexShader);

    GLuint fragmentShader = glCreateShader(GL_FRAGMENT_SHADER);
    glShaderSource(fragmentShader, 1, &fragmentShaderSource, NULL);
    glCompileShader(fragmentShader);

    state->shaderProgram = glCreateProgram();
    glAttachShader(state->shaderProgram, vertexShader);
    glAttachShader(state->shaderProgram, fragmentShader);
    glLinkProgram(state->shaderProgram);
    glDeleteShader(vertexShader);
    glDeleteShader(fragmentShader);

    float vertices[] = {
        // Positions   // TexCoords
        -0.5f,  0.5f,  0.0f, 0.0f,
        -0.5f, -0.5f,  0.0f, 1.0f,
         0.5f, -0.5f,  1.0f, 1.0f,

        -0.5f,  0.5f,  0.0f, 0.0f,
         0.5f, -0.5f,  1.0f, 1.0f,
         0.5f,  0.5f,  1.0f, 0.0f
    };

    glGenVertexArrays(1, &state->VAO);
    glGenBuffers(1, &state->VBO);

    glBindVertexArray(state->VAO);
    glBindBuffer(GL_ARRAY_BUFFER, state->VBO);
    glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), vertices, GL_STATIC_DRAW);

    glVertexAttribPointer(0, 2, GL_FLOAT, GL_FALSE, 4 * sizeof(float), (void*)0);
    glEnableVertexAttribArray(0);

    glVertexAttribPointer(1, 2, GL_FLOAT, GL_FALSE, 4 * sizeof(float), (void*)(2 * sizeof(float)));
    glEnableVertexAttribArray(1);

    // Load preloaded WebP texture from virtual filesystem
    state->texture = createTexture("assets/textures/clear_01.webp");

    printf("Application initialized successfully\n");
    return SDL_APP_CONTINUE;
}

// Called for every incoming SDL event
SDL_AppResult SDL_AppEvent(void* appstate, SDL_Event* event)
{
    (void)appstate;

    if (event->type == SDL_EVENT_QUIT)
    {
        return SDL_APP_SUCCESS;
    }

    return SDL_APP_CONTINUE;
}

// Called once per frame to update and render
SDL_AppResult SDL_AppIterate(void* appstate)
{
    AppState* state = (AppState*)appstate;

    int display_w, display_h;
    SDL_GetWindowSizeInPixels(state->window, &display_w, &display_h);
    glViewport(0, 0, display_w, display_h);

    glClearColor(0.2f, 0.25f, 0.3f, 1.0f);
    glClear(GL_COLOR_BUFFER_BIT);

    if (state->texture)
    {
        glUseProgram(state->shaderProgram);
        glActiveTexture(GL_TEXTURE0);
        glBindTexture(GL_TEXTURE_2D, state->texture);
        glBindVertexArray(state->VAO);
        glDrawArrays(GL_TRIANGLES, 0, 6);
    }

    SDL_GL_SwapWindow(state->window);

    return SDL_APP_CONTINUE;
}

// Called once when the application is shutting down
void SDL_AppQuit(void* appstate, SDL_AppResult result)
{
    (void)result;
    AppState* state = (AppState*)appstate;

    if (state)
    {
        if (state->texture) glDeleteTextures(1, &state->texture);
        if (state->VAO) glDeleteVertexArrays(1, &state->VAO);
        if (state->VBO) glDeleteBuffers(1, &state->VBO);
        if (state->shaderProgram) glDeleteProgram(state->shaderProgram);

        if (state->gl_context)
        {
            SDL_GL_DestroyContext(state->gl_context);
        }
        if (state->window)
        {
            SDL_DestroyWindow(state->window);
        }

        delete state;
    }

    SDL_Quit();
}

Step 6: Create Configuration and Build Scripts Шаг 6: Создание скриптов конфигурации и сборки

Create two helper batch scripts in the project root to automate CMake configuration with Emscripten and file copying: Создайте два вспомогательных bat-файла в корне проекта для автоматизации конфигурации CMake через Emscripten и копирования скомпилированных файлов:

This script compiles the project in parallel, ensures the output folders exist, and copies app.data to public\ and app.js / app.wasm to public\js\ automatically: Этот скрипт компилирует проект параллельно, проверяет наличие папок и автоматически копирует app.data в public\, а app.js и app.wasm — в public\js\: 

@echo off
pushd "%~dp0dist\web"
cmake --build . --parallel
popd

if not exist "%~dp0public\js" mkdir "%~dp0public\js"
if exist "%~dp0dist\web\app.data" copy /y "%~dp0dist\web\app.data" "%~dp0public\"
copy /y "%~dp0dist\web\app.wasm" "%~dp0public\js\"
copy /y "%~dp0dist\web\app.js" "%~dp0public\js\"

Step 8: Run a Local HTTP Server Шаг 8: Запуск локального HTTP-сервера

Web browsers do not allow loading WebAssembly (.wasm) directly via the file:// protocol due to CORS security policies. You must serve the public directory using a local HTTP server: Веб-браузеры блокируют загрузку WebAssembly (.wasm) через протокол file:// из соображений безопасности (CORS). Папку public необходимо раздавать через локальный HTTP-сервер:

Option A: Python 3 Вариант А: Python 3

Requires Python (defaults to port 8000): Требуется установленный интерпретатор Python (по умолчанию порт 8000): 

python -m http.server -d public

Option B: Node.js (http-server) Вариант Б: Node.js (http-server)

Requires Node.js: Требуется установленный Node.js: 

npx http-server public -c-1

Open the local server URL in your web browser (e.g., http://localhost:8000). Open Developer Tools (F12) Console to observe the clean standard console text output: Откройте адрес локального сервера в веб-браузере (например, http://localhost:8000). Откройте консоль разработчика (F12), чтобы увидеть стандартный вывод консоли: 

Anisotropic filtering enabled. Max: 16.0
Application initialized successfully

You will see the textured wooden crate rendered smoothly in your web browser powered by WebAssembly, SDL3_image, WebP decoding, and WebGL 2.0! Вы увидите отрендеренный текстурированный деревянный ящик прямо в веб-браузере благодаря WebAssembly, SDL3_image, декодированию WebP и WebGL 2.0!
