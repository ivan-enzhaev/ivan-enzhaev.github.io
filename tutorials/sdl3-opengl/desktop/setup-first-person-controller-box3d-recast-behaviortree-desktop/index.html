First-Person Controller with Box3D Physics, Recast Navigation, BehaviorTree.CPP, SDL3, and OpenGL 3.3 First-Person контроллер с физикой Box3D, Recast Navigation, BehaviorTree.CPP, SDL3 и OpenGL 3.3

A step-by-step guide to downloading and running the starter project featuring a First-Person (FPS) capsule controller, Box3D rigid body physics, Recast/Detour navigation mesh pathfinding, BehaviorTree.CPP 4.x enemy AI, a textured falling cube loaded via cgltf, and color-coded debug overlays on Windows and Ubuntu. Пошаговое руководство по скачиванию и запуску стартового проекта с капсульным First-Person (FPS) контроллером, физикой твердых тел Box3D, поиском путей по NavMesh через Recast/Detour, AI врагов на BehaviorTree.CPP 4.x, текстурированным падающим кубом через cgltf и цветовой отладочной визуализацией под Windows и Ubuntu.

Step 1: Download Project Archive (.zip) Шаг 1: Скачивание zip-архива проекта

Download the source code archive directly from the GitHub repository: Скачайте архив исходного кода напрямую из репозитория GitHub:

Download Repository (.zip) Скачать репозиторий (.zip) View on GitHub Открыть на GitHub

Option A: Windows Вариант A: Windows

Extract the downloaded fps-starter-box3d-recast-behaviortree-opengl-sdl3-desktop-main.zip archive so that its files reside in: Распакуйте скачанный архив fps-starter-box3d-recast-behaviortree-opengl-sdl3-desktop-main.zip так, чтобы его содержимое находилось в: 

C:\projects\fps-starter-box3d-recast-behaviortree-opengl-sdl3-desktop

Option B: Ubuntu (Terminal) Вариант B: Ubuntu (Терминал)

On Ubuntu, you can download and extract the repository in your terminal using wget and unzip: В Ubuntu вы можете скачать и распаковать репозиторий в терминале с помощью wget и unzip: 

sudo apt update && sudo apt install -y wget unzip

mkdir -p ~/projects
cd ~/projects

wget https://github.com/ivan-enzhaev/fps-starter-box3d-recast-behaviortree-opengl-sdl3-desktop/archive/refs/heads/main.zip -O fps-starter-box3d-recast-behaviortree-opengl-sdl3-desktop-main.zip
unzip -o fps-starter-box3d-recast-behaviortree-opengl-sdl3-desktop-main.zip
mv fps-starter-box3d-recast-behaviortree-opengl-sdl3-desktop-main fps-starter-box3d-recast-behaviortree-opengl-sdl3-desktop
rm -f fps-starter-box3d-recast-behaviortree-opengl-sdl3-desktop-main.zip

cd ~/projects/fps-starter-box3d-recast-behaviortree-opengl-sdl3-desktop

Step 3: Build & Run the Application Шаг 3: Сборка и запуск приложения

The repository already includes pre-configured scripts to configure, build, and run the project. Репозиторий уже содержит готовые скрипты для конфигурации, сборки и запуска проекта.

Windows (Command Prompt / PowerShell)

Run the batch scripts sequentially from the project root folder: Последовательно запустите командные файлы из корневой папки проекта: 

config-exe.bat
build-exe.bat
run-exe.bat

Ubuntu (Terminal)

Grant execution permissions to the shell scripts first, then run them sequentially: Сначала предоставьте права на исполнение shell-скриптам, затем последовательно запустите их: 

chmod +x config-bin.sh build-bin.sh run-bin.sh

./config-bin.sh
./build-bin.sh
./run-bin.sh
