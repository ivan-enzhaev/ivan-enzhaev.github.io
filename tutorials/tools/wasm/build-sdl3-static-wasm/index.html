Building SDL3 Static Library for WebAssembly (Emscripten & CMake) Сборка статической библиотеки SDL3 для WebAssembly (Emscripten и CMake)

A guide to compiling SDL3 source code into a static library (libSDL3.a) for WebAssembly on Windows using Emscripten and CMake. Руководство по компиляции исходного кода SDL3 в статическую библиотеку (libSDL3.a) для WebAssembly на Windows с помощью Emscripten и CMake.

If you haven't set up Emscripten SDK and CMake on your machine, follow the Если вы еще не настроили Emscripten SDK и CMake на своем компьютере, следуйте инструкции: Emscripten & CMake Setup Guide Руководство по настройке Emscripten и CMake

Step 1: Download SDL3 Source Code Шаг 1: Скачивание исходного кода SDL3

Download the latest SDL3 source archive (.zip or .tar.gz) from the official GitHub releases page: Скачайте последний архив с исходным кодом SDL3 (.zip или .tar.gz) с официальной страницы релизов GitHub:

Download SDL3 Releases Скачать релизы SDL3

Extract the downloaded archive to a convenient directory on your machine. Распакуйте скачанный архив в удобную директорию на вашем компьютере.

Step 2: Create the Build Script Шаг 2: Создание скрипта сборки

In the root directory of the extracted SDL3 source folder, create an empty file named build-emscripten.bat and paste the following content into it: В корневой директории распакованного исходного кода SDL3 создайте пустой файл build-emscripten.bat и вставьте в него следующее содержимое: 

@echo off

if not exist build-emscripten mkdir build-emscripten
cd build-emscripten

:: Clean old cache if it exists
if exist CMakeCache.txt del CMakeCache.txt
if exist CMakeFiles rmdir /s /q CMakeFiles

call emcmake cmake .. ^
  -G "MinGW Makefiles" ^
  -DCMAKE_BUILD_TYPE=Release ^
  -DCMAKE_INSTALL_PREFIX=C:/libs/sdl3-3.4.14-wasm ^
  -DBUILD_SHARED_LIBS=OFF ^
  -DSDL_SHARED=OFF ^
  -DSDL_STATIC=ON ^
  -DSDL_TESTS=OFF ^
  -DSDL_EXAMPLES=OFF

call emmake cmake --build . --config Release --parallel 8 --target install

Step 3: Run and Compile Шаг 3: Запуск и сборка

Double-click build-emscripten.bat or run it via Command Prompt. Once completed, your compiled static library libSDL3.a along with header files will be installed in the C:/libs/sdl3-3.4.14-wasm directory. Дважды кликните по build-emscripten.bat или запустите его через командную строку. После завершения собранная статическая библиотека libSDL3.a вместе с заголовочными файлами будет установлена в директорию C:/libs/sdl3-3.4.14-wasm.
