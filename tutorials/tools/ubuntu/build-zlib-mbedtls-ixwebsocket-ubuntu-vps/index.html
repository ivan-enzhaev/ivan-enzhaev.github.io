Building ZLIB, MBedTLS & IXWebSocket 12.0.1 Static Libraries on Ubuntu VPS Сборка статических библиотек ZLIB, MBedTLS и IXWebSocket 12.0.1 на Ubuntu VPS

Prerequisite guide: Предварительное руководство:
  • Setting Up C/C++ Development Environment on Ubuntu VPS Настройка среды разработки C/C++ на Ubuntu VPS

This guide covers installing key library headers and compiling specific static versions of ZLIB (v1.3.2), MBedTLS (mbedtls-4.2.0), and IXWebSocket (v12.0.1) on your headless Ubuntu VPS using CMake and Ninja. В этом руководстве описана установка ключевых заголовков библиотек и компиляция конкретных статических версий ZLIB (v1.3.2), MBedTLS (mbedtls-4.2.0) и IXWebSocket (v12.0.1) на вашем сервере Ubuntu VPS с использованием CMake и Ninja.

1. Additional C/C++ Library Headers 1. Дополнительные заголовки библиотек C/C++

Install common development headers required for building networking and cryptography static libraries (such as ZLIB and MBedTLS): Установите основные заголовки библиотек, необходимые для сборки сетевых и криптографических статических библиотек (таких как ZLIB и MBedTLS): 

sudo apt update && sudo apt install -y zlib1g-dev libssl-dev pkg-config

2. Build and Install ZLIB Static Library (v1.3.2) 2. Сборка и установка статической библиотеки ZLIB (v1.3.2)

Clone release tag v1.3.2 of ZLIB, build the static library using CMake & Ninja, and install it into system directories: Клонируйте релизный тег v1.3.2 ZLIB, соберите статическую библиотеку с помощью CMake и Ninja и установите её в системные директории: 

git clone --branch v1.3.2 --depth 1 https://github.com/madler/zlib.git ~/zlib
cd ~/zlib
cmake -B dist -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_SHARED_LIBS=OFF
cmake --build dist
sudo cmake --install dist

3. Build and Install MBedTLS Static Library (mbedtls-4.2.0) 3. Сборка и установка статической библиотеки MBedTLS (mbedtls-4.2.0)

Clone release tag mbedtls-4.2.0 of MBedTLS, update git submodules, build the static libraries, and install them: Клонируйте релизный тег mbedtls-4.2.0 MBedTLS, обновите подмодули git, соберите статические библиотеки и установите их: 

git clone --branch mbedtls-4.2.0 --recursive --depth 1 https://github.com/Mbed-TLS/mbedtls.git ~/mbedtls
cd ~/mbedtls
cmake -B dist -G Ninja -DCMAKE_BUILD_TYPE=Release -DENABLE_PROGRAMS=OFF -DENABLE_TESTING=OFF -DUSE_SHARED_MBEDTLS_LIBRARY=OFF
cmake --build dist
sudo cmake --install dist

4. Build and Install IXWebSocket (v12.0.1) 4. Сборка и установка IXWebSocket (v12.0.1)

Clone release tag v12.0.1 of IXWebSocket and build it using the installed MBedTLS TLS provider and ZLIB: Клонируйте релизный тег v12.0.1 IXWebSocket и соберите его с использованием установленного провайдера MBedTLS и ZLIB: 

git clone --branch v12.0.1 --depth 1 https://github.com/machinezone/IXWebSocket.git ~/IXWebSocket
cd ~/IXWebSocket
cmake -B dist -G Ninja -DCMAKE_BUILD_TYPE=Release -DUSE_MBED_TLS=ON -DUSE_TLS=ON -DBUILD_SHARED_LIBS=OFF
cmake --build dist
sudo cmake --install dist

5. Verification 5. Проверка установки

Verify that the package headers are present and the compiled static libraries exist under /usr/local/lib/: Убедитесь, что заголовки пакетов присутствуют, а собранные статические библиотеки находятся в /usr/local/lib/: 

dpkg -l zlib1g-dev libssl-dev pkg-config | cat
ls -l /usr/local/lib/libz.a /usr/local/lib/libmbedcrypto.a /usr/local/lib/libmbedtls.a /usr/local/lib/libixwebsocket.a
Next Step: All static libraries are now compiled and installed! You can now link libixwebsocket.a, libmbedtls.a, libmbedx509.a, libmbedcrypto.a, and libz.a into your C++ projects. Следующий шаг: Все статические библиотеки успешно собраны и установлены! Теперь вы можете линковать libixwebsocket.a, libmbedtls.a, libmbedx509.a, libmbedcrypto.a и libz.a в ваши проекты C++.
