Building Zlib Static Library for Ubuntu VPS (GCC & CMake) Сборка статической библиотеки Zlib для Ubuntu VPS (GCC и CMake)

A beginner-friendly guide to connecting to your remote server from Windows and compiling Zlib into a static library (libz.a). Понятное для новичков руководство по подключению к удаленному серверу из Windows и компиляции Zlib в статическую библиотеку (libz.a).

If you haven't set up the build tools on your server yet, follow the Если вы еще не настроили инструменты сборки на своем сервере, следуйте инструкции: Ubuntu VPS C++ Setup Guide Руководство по настройке C++ на Ubuntu VPS

Step 1: Connect to Your VPS from Windows Шаг 1: Подключение к VPS из Windows

Open PowerShell or Command Prompt (cmd) on your Windows machine and connect to your server via SSH (replace 192.0.2.100 with your server's actual IP address): Откройте PowerShell или Командную строку (cmd) на вашем компьютере с Windows и подключитесь к серверу по SSH (замените 192.0.2.100 на реальный IP-адрес вашего сервера): 

ssh root@192.0.2.100

If prompted, type yes to accept the server host key, then enter your password. Если появится запрос, введите yes для подтверждения ключа хоста, а затем введите ваш пароль.

Step 2: Download and Extract Zlib Source Шаг 2: Скачивание и распаковка исходного кода Zlib

Create a dedicated folder for your source libraries, download the latest official Zlib tarball directly on the server, and extract it: Создайте отдельную папку для исходных кодов библиотек, скачайте последний официальный архив Zlib прямо на сервере и распакуйте его: 

# Create and enter the working directory
mkdir -p ~/src && cd ~/src

# Download the Zlib 1.3.1 source release archive
wget https://github.com/madler/zlib/releases/download/v1.3.1/zlib-1.3.1.tar.gz

# Extract the archive
tar -xzf zlib-1.3.1.tar.gz

# Navigate into the extracted directory
cd zlib-1.3.1

Step 3: Create the Build Script Шаг 3: Создание скрипта сборки

Create a new shell script file named build-ubuntu-static.sh inside the Zlib folder using the nano text editor: Создайте новый файл скрипта с именем build-ubuntu-static.sh внутри папки Zlib с помощью текстового редактора nano: 

nano build-ubuntu-static.sh

Paste the following shell script contents into the editor: Вставьте следующее содержимое скрипта в редактор: 

#!/bin/bash

mkdir -p build-ubuntu-static
cd build-ubuntu-static

# Clean old cache completely
rm -f CMakeCache.txt
rm -rf CMakeFiles

cmake .. \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX=/home/$USER/libs/zlib-1.3.1-ubuntu \
  -DBUILD_SHARED_LIBS=OFF \
  -G "Ninja"

cmake --build . --config Release --target install
How to save in Nano: Как сохранить файл в Nano: Press Ctrl + O, hit Enter to confirm the filename, then press Ctrl + X to exit. Нажмите Ctrl + O, затем Enter для подтверждения имени файла, после чего нажмите Ctrl + X для выхода.

Step 4: Make Executable and Compile Шаг 4: Предоставление прав на исполнение и сборка

Grant execution permissions to the script using chmod +x and execute it: Предоставьте права на исполнение скрипту с помощью chmod +x и запустите его: 

chmod +x build-ubuntu-static.sh
./build-ubuntu-static.sh

Once completed, verify that the compiled static library (libz.a) and headers (zlib.h, zconf.h) are properly installed in your destination directory: После завершения убедитесь, что собранная статическая библиотека (libz.a) и заголовки (zlib.h, zconf.h) успешно установлены в целевую директорию: 

ls -la ~/libs/zlib-1.3.1-ubuntu/lib
ls -la ~/libs/zlib-1.3.1-ubuntu/include
