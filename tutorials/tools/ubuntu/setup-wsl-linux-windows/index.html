Installing and Managing Linux Distributions on Windows using WSL Установка и управление дистрибутивами Linux на Windows через WSL

A beginner-friendly guide to installing Ubuntu and Fedora directly from the catalog, configuring user accounts and package managers, and managing WSL 2 instances via Command Prompt (CMD) or PowerShell. Пошаговое руководство для начинающих по установке Ubuntu и Fedora напрямую из каталога, созданию пользователя, обновлению пакетов и управлению WSL 2 через Командную строку (CMD) или PowerShell.

Prerequisites: Windows 10 (version 2004+, Build 19041+) or Windows 11. Hardware virtualization (VT-x / AMD-V) must be enabled (verify in Task Manager → Performance → CPU → Virtualization: Enabled). Предварительные требования: Windows 10 (версия 2004+, сборка 19041+) или Windows 11. Должна быть включена аппаратная виртуализация (VT-x / AMD-V) — проверьте в Диспетчере задач → Производительность → ЦП → Виртуализация: Включено.

Step 1: Install a Linux Distribution Шаг 1: Установка дистрибутива Linux

Open Command Prompt (CMD) as Administrator (or PowerShell) and install your preferred Linux distribution: Откройте Командную строку (CMD) от имени Администратора (или PowerShell) и установите нужный дистрибутив:

Option A: Installing Ubuntu Вариант A: Установка Ubuntu

Installs the latest LTS release of Ubuntu from the catalog: Устанавливает актуальный LTS-релиз Ubuntu из каталога: 

wsl --install -d Ubuntu
You can also specify an exact LTS version like wsl --install -d Ubuntu-24.04. Также можно указать конкретную версию, например wsl --install -d Ubuntu-24.04.
Option B: Installing Fedora Вариант B: Установка Fedora

Installs the official Fedora Linux distribution directly from the catalog: Устанавливает официальный дистрибутив Fedora Linux напрямую из каталога: 

wsl --install -d FedoraLinux-44

Step 2: Initial User Setup & Package Updates Шаг 2: Первоначальная настройка пользователя и обновление пакетов

Upon first launch, you will be prompted to create a new UNIX username and password. Once logged in, update the package manager: При первом запуске вам будет предложено создать UNIX-пользователя и пароль. После входа в систему обновите пакетный менеджер:

For Ubuntu (APT): Для Ubuntu (APT): 

sudo apt update && sudo apt upgrade -y

For Fedora (DNF): Для Fedora (DNF): 

sudo dnf upgrade --refresh -y

Step 3: Check and List Installed Distributions Шаг 3: Проверка и список установленных дистрибутивов

Open Command Prompt (CMD) to verify that your new Linux distribution is installed and running on WSL 2: Откройте Командную строку (CMD), чтобы убедиться, что ваш дистрибутив Linux установлен и работает на WSL 2:

1. View Installed Distributions with Details 1. Просмотр установленных дистрибутивов с подробностями

Displays distro name, current state (Running / Stopped), and engine version (WSL 1 or WSL 2): Отображает имя дистрибутива, статус (Running / Stopped) и версию подсистемы (WSL 1 или WSL 2): 

wsl --list --verbose
:: Shortcut:
wsl -l -v

2. View Only Running Distributions 2. Просмотр только запущенных в данный момент дистрибутивов 

wsl --list --running

3. View Other Distributions Available for Install 3. Просмотр других доступных для установки дистрибутивов 

wsl --list --online
:: Shortcut:
wsl -l -o

Step 4: Useful WSL Management Commands Шаг 4: Полезные команды управления WSL

Command (CMD / PowerShell)Команда (CMD / PowerShell) DescriptionОписание
wsl -d <DistroName> Launch a specific distribution (e.g. wsl -d Ubuntu)Запустить определенный дистрибутив (например, wsl -d Ubuntu)
wsl --set-default <DistroName> Set the default distribution for typing wslСделать дистрибутив основным по умолчанию при вводе wsl
wsl --set-default-version 2 Configure all future installs to use WSL 2 engineЗадать WSL 2 версией по умолчанию для будущих установок
wsl --terminate <DistroName> Immediately stop a specific running distroПринудительно остановить конкретный дистрибутив
wsl --shutdown Completely shut down all running WSL 2 Linux instances & free RAMПолностью завершить все работающие дистрибутивы WSL 2 и освободить ОЗУ
wsl --unregister <DistroName> Permanently delete a distro and its virtual disk (irreversible)Безвозвратно удалить дистрибутив и его виртуальный диск
