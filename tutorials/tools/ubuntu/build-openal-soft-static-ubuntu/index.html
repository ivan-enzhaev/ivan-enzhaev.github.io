Building OpenAL-Soft Static Library for Ubuntu (GCC & CMake) Сборка статической библиотеки OpenAL-Soft для Ubuntu (GCC и CMake)

A guide to compiling OpenAL-Soft source code into a static library (libopenal.a) on Ubuntu. Руководство по компиляции исходного кода OpenAL-Soft в статическую библиотеку (libopenal.a) в Ubuntu.

If you haven't set up C/C++ development tools on your Ubuntu machine, follow the Если вы еще не настроили инструменты разработки C/C++ на вашей системе Ubuntu, следуйте инструкции: Ubuntu C/C++ Development Environment Setup Guide Руководство по настройке среды разработки C/C++ на Ubuntu

Step 1: Install Build Dependencies Шаг 1: Установка зависимостей сборки

Ensure that wget and audio development libraries (such as ALSA and PipeWire) are installed on your system to download archives and support sound backends: Убедитесь, что wget и библиотеки аудио-разработки (такие как ALSA и PipeWire) установлены в вашей системе для скачивания архивов и поддержки звуковых бэкендов: 

sudo apt update && sudo apt install -y wget libasound2-dev libpipewire-0.3-dev

Step 2: Download OpenAL-Soft Source Code Archive Шаг 2: Скачивание архива исходного кода OpenAL-Soft

You can browse the official GitHub releases page to check the latest available release assets: Вы можете перейти на страницу релизов GitHub, чтобы посмотреть список доступных версий:

View OpenAL-Soft Releases Смотреть релизы OpenAL-Soft

Download and extract the source archive for version 1.25.2 using wget: Скачайте и распакуйте архив с исходным кодом версии 1.25.2 с помощью wget: 

cd ~
wget https://github.com/kcat/openal-soft/archive/refs/tags/1.25.2.tar.gz -O openal-soft-1.25.2.tar.gz
tar -xzf openal-soft-1.25.2.tar.gz
cd openal-soft-1.25.2

Step 3: Create the Build Script Шаг 3: Создание скрипта сборки

In the root directory of the extracted OpenAL-Soft source folder, create a script named build-ubuntu-static.sh with the following content: В корневой директории извлеченного исходного кода OpenAL-Soft создайте файл build-ubuntu-static.sh со следующим содержимым: 

#!/usr/bin/env bash
set -e

BUILD_DIR="build-ubuntu-static"

rm -rf "$BUILD_DIR"
mkdir -p "$BUILD_DIR"
cd "$BUILD_DIR"

cmake .. \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX="$HOME/libs/openal-soft-1.25.2-ubuntu" \
  -DLIBTYPE=STATIC \
  -DALSOFT_EXAMPLES=OFF \
  -DALSOFT_TESTS=OFF \
  -DALSOFT_UTILS=OFF

cmake --build . --config Release --parallel $(nproc) --target install
Note: Примечание: The option -DLIBTYPE=STATIC explicitly instructs OpenAL-Soft to build as a static library (libopenal.a). Setting flags like -DALSOFT_EXAMPLES=OFF, -DALSOFT_TESTS=OFF, and -DALSOFT_UTILS=OFF disables extra utilities and test binaries to speed up compilation. Опция -DLIBTYPE=STATIC явно указывает OpenAL-Soft собираться как статическая библиотека (libopenal.a). Флаги -DALSOFT_EXAMPLES=OFF, -DALSOFT_TESTS=OFF и -DALSOFT_UTILS=OFF отключают вспомогательные утилиты и тесты, что значительно ускоряет сборку.

Step 4: Run, Compile, and Clean Up Шаг 4: Запуск, сборка и очистка

Grant execution permissions to the script and run it in your terminal: Сделайте скрипт исполняемым и запустите его в терминале: 

chmod +x build-ubuntu-static.sh
./build-ubuntu-static.sh

Upon completion, your compiled static library (libopenal.a) along with headers will be installed in your specified CMAKE_INSTALL_PREFIX directory. После успешного завершения собранная статическая библиотека (libopenal.a) вместе с заголовочными файлами будет установлена по пути, указанному в CMAKE_INSTALL_PREFIX.

Once installed, you can safely remove the temporary source directory and the downloaded archive: После установки вы можете безопасно удалить временную директорию с исходным кодом и скачанный архив: 

cd ~ && rm -rf ~/openal-soft-1.25.2 ~/openal-soft-1.25.2.tar.gz
