How to Setup and Use SFTP in Sublime Text 4 Настройка и использование SFTP в Sublime Text 4

Security Warning: Never commit plain-text passwords or secret credentials inside your sftp-config.json file to public repositories. Add sftp-config.json to your .gitignore file and use SSH key authentication. Предупреждение по безопасности: Никогда не сохраняйте пароли в открытом виде в файле sftp-config.json при отправке кода в публичные репозитории. Добавьте sftp-config.json в файл .gitignore и используйте аутентификацию по SSH-ключам.

This guide covers how to install the SFTP package in Sublime Text 4, configure automated uploads on save, and sync local directories with a remote server over SSH using key authentication on Windows. В этом руководстве рассмотрено, как установить пакет SFTP в Sublime Text 4, настроить автоматическую загрузку при сохранении и синхронизировать локальные папки с удаленным сервером по SSH с использованием SSH-ключей в Windows.

1. Installation via Package Control 1. Установка через Package Control

  1. Open Sublime Text 4 and press Ctrl + Shift + P (Windows/Linux) or Cmd + Shift + P (Mac) to open the Command Palette. Откройте Sublime Text 4 и нажмите Ctrl + Shift + P (Windows/Linux) или Cmd + Shift + P (Mac), чтобы открыть палитру команд.
  2. Type Package Control: Install Package and hit Enter. Введите Package Control: Install Package и нажмите Enter.
  3. Search for SFTP (by wbond) and press Enter to install. Найдите SFTP (автор wbond) и нажмите Enter для установки.

2. Project Configuration (sftp-config.json) 2. Конфигурация проекта (sftp-config.json)

Open your project folder in Sublime Text (File > Open Folder...), right-click the root folder in the sidebar, and choose SFTP/FTP > Map to Remote.... Replace the file contents with the following: Откройте папку проекта в Sublime Text (File > Open Folder...), нажмите правой кнопкой мыши по корневой папке в боковой панели и выберите SFTP/FTP > Map to Remote.... Замените содержимое файла следующим кодом: 

{
    "type": "sftp",

    "save_before_upload": true,
    "upload_on_save": true,
    "sync_down_on_open": false,
    "sync_skip_deletes": false,
    "sync_same_age": true,
    "confirm_downloads": false,
    "confirm_sync": true,
    "confirm_overwrite_newer": false,
    "allow_config_upload": true,
    
    "host": "YOUR_SERVER_IP",
    "user": "root",
    "ssh_key_file": "C:/Users/YOUR_WINDOWS_USERNAME/.ssh/id_ed25519",
    "port": "22",
    
    "remote_path": "/root/my_ix_hello_server/",
    "ignore_regexes": [
        "\\.sublime-(project|workspace)", "sftp-config(-alt\\d?)?\\.json",
        "sftp-settings\\.json", "/venv/", "\\.svn/", "\\.hg/", "\\.git/",
        "\\.bzr", "_darcs", "CVS", "\\.DS_Store", "Thumbs\\.db", "desktop\\.ini",
        "/dist/", "dist/"
    ],

    "connect_timeout": 30
}

3. Configuration Parameters Explained 3. Описание параметров конфигурации

Setting Value Description Описание
upload_on_save true Automatically uploads the current file to the remote server every time you save. Автоматически загружает текущий файл на удаленный сервер при каждом сохранении.
ssh_key_file Path Path to your private SSH key on Windows. Replaces plain-text password authentication. Путь к вашему приватному SSH-ключу в Windows. Заменяет аутентификацию по открытому паролю.
allow_config_upload true Prevents upload popup warnings when saving or syncing sftp-config.json itself. Предотвращает появление всплывающих предупреждений при сохранении или синхронизации sftp-config.json.
confirm_sync true Prompts a confirmation dialog prior to running full folder synchronization. Запрашивает подтверждение перед запуском полной синхронизации папок.
ignore_regexes Array Excludes specified files and directories (like .git, /venv/, and .DS_Store) from remote transfer. Исключает указанные файлы и каталоги (например, .git, /venv/ и .DS_Store) из передачи.

4. Recommended Security: SSH Key Authentication (Windows) 4. Рекомендуемая безопасность: Аутентификация по SSH-ключу (Windows)

Instead of storing your server password in plain text, set up SSH key authentication from Windows: Вместо хранения пароля сервера в открытом виде настройте аутентификацию по SSH-ключу из Windows:

  1. Open PowerShell on Windows and generate an SSH key pair: Откройте PowerShell в Windows и сгенерируйте пару SSH-ключей: 
    ssh-keygen -t ed25519
    (Press Enter for all prompts to accept default settings). (Нажимайте Enter на все запросы, чтобы принять настройки по умолчанию).
  2. Copy your public key to the Linux server by running: Скопируйте ваш публичный ключ на сервер Linux, выполнив команду: 
    Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub | ssh root@YOUR_SERVER_IP "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"
    Note: $env:USERPROFILE is a PowerShell variable that automatically points to your Windows user folder (e.g., C:\Users\YourName). You can paste this command without changing it. Примечание: $env:USERPROFILE — это переменная PowerShell, которая автоматически указывает на вашу папку пользователя Windows (например, C:\Users\ВашеИмя). Вы можете вставить эту команду без изменений.
  3. Update sftp-config.json in Sublime Text 4. Replace the "password" line with "ssh_key_file": Обновите sftp-config.json в Sublime Text 4. Замените строку "password" на "ssh_key_file": 
    "ssh_key_file": "C:/Users/YOUR_WINDOWS_USERNAME/.ssh/id_ed25519"
    Note: sftp-config.json is a JSON configuration file. In JSON, paths must use forward slashes (/) instead of Windows backslashes (\). Примечание: sftp-config.json — это конфигурационный файл формата JSON. В формате JSON в путях необходимо использовать прямые слеши (/) вместо обратных (\).
