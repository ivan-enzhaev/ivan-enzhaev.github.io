Building SFML 3 Static Library for Ubuntu & WSL (GCC, CMake & Ninja) Сборка статической библиотеки SFML 3 для Ubuntu и WSL (GCC, CMake и Ninja)

A guide to compiling SFML 3 source code into static libraries on Ubuntu (native or via Windows WSL2) for Desktop, GUI, or Headless Server setups using CMake, Ninja, and GCC. Руководство по компиляции исходного кода SFML 3 в статические библиотеки в Ubuntu (нативно или через Windows WSL2) для десктопа, GUI или headless-сервера с помощью CMake, Ninja и GCC.

If you haven't set up C/C++ development tools on your Ubuntu machine or WSL distribution, follow the Если вы еще не настроили инструменты разработки C/C++ на вашей системе Ubuntu или в дистрибутиве WSL, следуйте инструкции: Ubuntu C/C++ Development Environment Setup Guide Руководство по настройке среды разработки C/C++ на Ubuntu
Windows Setup (WSL2 & Ubuntu): Настройка для пользователей Windows (WSL2 и Ubuntu):

1. If WSL is not installed yet, open CMD or PowerShell as Administrator and install Ubuntu: 1. Если WSL еще не установлен, откройте CMD или PowerShell от имени администратора и установите Ubuntu: 

wsl --install -d Ubuntu

2. Launch your Ubuntu distribution from CMD or PowerShell: 2. Запустите дистрибутив Ubuntu из CMD или PowerShell: 

wsl -d Ubuntu

Step 1: Install Dependencies Шаг 1: Установка зависимостей

Select your target environment to view the required system packages: Выберите вашу целевую среду для просмотра необходимых системных пакетов:

Install the development headers required for X11, UDev (joysticks/gamepads), HarfBuzz/FreeType (fonts), OpenGL, and audio backends: Установите заголовочные файлы для X11, UDev (джойстики и геймпады), HarfBuzz/FreeType (шрифты), OpenGL и аудиосистем: 

sudo apt update && sudo apt install -y \
  build-essential cmake ninja-build wget nano \
  libudev-dev \
  libx11-dev libxrandr-dev libxcursor-dev libxi-dev \
  libgl1-mesa-dev libegl1-mesa-dev \
  libharfbuzz-dev libfreetype-dev \
  libasound2-dev libopenal-dev libvorbis-dev libflac-dev

For a minimal build without graphics or audio, only the core build tools are required: Для минимальной сборки без графики и звука требуются только базовые инструменты сборки: 

sudo apt update && sudo apt install -y build-essential cmake ninja-build wget nano

Step 2: Download SFML 3 Source Code Шаг 2: Скачивание исходного кода SFML 3

Check and download the latest release (3.1.0) directly from the official SFML repository on GitHub: Проверьте и скачайте последнюю версию (3.1.0) напрямую со страницы релизов SFML на GitHub:

Open SFML Releases (GitHub) Открыть релизы SFML (GitHub) Direct Download SFML-3.1.0 (.tar.gz) Прямое скачивание SFML-3.1.0 (.tar.gz)

You can download and extract it directly via wget in the terminal (native Ubuntu terminal or WSL bash): Вы можете скачать и распаковать архив напрямую с помощью wget в терминале (в нативном терминале Ubuntu или в консоли WSL): 

cd ~
wget https://github.com/SFML/SFML/archive/refs/tags/3.1.0.tar.gz -O SFML-3.1.0.tar.gz
tar -xzf SFML-3.1.0.tar.gz
cd SFML-3.1.0

Step 3: Create the Build Script Шаг 3: Создание скрипта сборки

In the root directory of the extracted SFML 3 source folder, open the nano text editor to create a script named build-ubuntu-static.sh: В корневой директории извлеченного исходного кода SFML 3 откройте текстовый редактор nano для создания файла build-ubuntu-static.sh: 

nano build-ubuntu-static.sh
How to use nano: Copy the code below, right-click in the terminal to paste it, press Ctrl + O (then Enter) to save, and press Ctrl + X to exit. Как пользоваться nano: Скопируйте код ниже, нажмите правую кнопку мыши в терминале для вставки, нажмите Ctrl + O (затем Enter) для сохранения и Ctrl + X для выхода.

Choose your environment and paste the corresponding script: Выберите вашу среду и вставьте соответствующий скрипт: 

#!/usr/bin/env bash
set -e

BUILD_DIR="build-ubuntu-static"

rm -rf "$BUILD_DIR"
mkdir -p "$BUILD_DIR"
cd "$BUILD_DIR"

cmake .. \
  -GNinja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX="$HOME/libs/sfml-3.1.0-ubuntu" \
  -DBUILD_SHARED_LIBS=OFF \
  -DSFML_BUILD_NETWORK=OFF \
  -DSFML_BUILD_EXAMPLES=OFF \
  -DSFML_BUILD_TEST_SUITE=OFF \
  -DSFML_BUILD_DOC=OFF

cmake --build . --config Release --parallel --target install
#!/usr/bin/env bash
set -e

BUILD_DIR="build-ubuntu-static"

rm -rf "$BUILD_DIR"
mkdir -p "$BUILD_DIR"
cd "$BUILD_DIR"

cmake .. \
  -GNinja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX="$HOME/libs/sfml-3.1.0-ubuntu" \
  -DBUILD_SHARED_LIBS=OFF \
  -DSFML_BUILD_NETWORK=OFF \
  -DSFML_BUILD_EXAMPLES=OFF \
  -DSFML_BUILD_TEST_SUITE=OFF \
  -DSFML_BUILD_DOC=OFF \
  -DSFML_BUILD_AUDIO=OFF \
  -DSFML_BUILD_GRAPHICS=OFF \
  -DSFML_BUILD_WINDOW=OFF

cmake --build . --config Release --parallel --target install
Note: Примечание: Setting -DSFML_BUILD_NETWORK=OFF excludes the Network module, avoiding external dependencies on Mbed TLS and Libssh2. Ensure that CMAKE_INSTALL_PREFIX matches your preferred installation path. Параметр -DSFML_BUILD_NETWORK=OFF исключает модуль Network, избавляя от внешних зависимостей Mbed TLS и Libssh2. Убедитесь, что CMAKE_INSTALL_PREFIX соответствует удобному для вас пути установки.

Step 4: Run, Compile, and Clean Up Шаг 4: Запуск, сборка и очистка

Grant execution permissions to the script and run it in your terminal: Сделайте скрипт исполняемым и запустите его в терминале: 

chmod +x build-ubuntu-static.sh
./build-ubuntu-static.sh

Upon completion, your static libraries (libsfml-graphics-s.a, libsfml-window-s.a, libsfml-system-s.a, and libsfml-audio-s.a) along with header files will be installed in your specified CMAKE_INSTALL_PREFIX directory (e.g. ~/libs/sfml-3.1.0-ubuntu). После успешного завершения собранные статические библиотеки (libsfml-graphics-s.a, libsfml-window-s.a, libsfml-system-s.a и libsfml-audio-s.a) вместе с заголовочными файлами будут установлены по пути, указанному в CMAKE_INSTALL_PREFIX (например, ~/libs/sfml-3.1.0-ubuntu).

Once installed, you can safely remove the temporary source directory and the downloaded archive: После установки вы можете безопасно удалить временную директорию с исходным кодом и скачанный архив: 

cd ~ && rm -rf ~/SFML-3.1.0 ~/SFML-3.1.0.tar.gz
