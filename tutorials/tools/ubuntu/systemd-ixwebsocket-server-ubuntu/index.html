Running IXWebSocket C++ Server as a Systemd Service on Ubuntu VPS Запуск C++ сервера IXWebSocket как службы Systemd на Ubuntu VPS

This guide covers how to set up, configure, and manage your compiled IXWebSocket C++ server executable as an automatic background systemd service on Ubuntu VPS. В этом руководстве описана настройка, включение и управление скомпилированным исполняемым файлом C++ сервера IXWebSocket в качестве автоматической фоновой службы systemd на Ubuntu VPS.

1. Create the Systemd Unit File 1. Создание файла юнита Systemd

Create a new service configuration file under /etc/systemd/system/ using a text editor: Создайте новый конфигурационный файл службы в /etc/systemd/system/ с помощью текстового редактора: 

sudo nano /etc/systemd/system/ixwebsocket-server.service

Paste the following unit configuration into the file: Вставьте следующую конфигурацию юнита в файл: 

[Unit]
Description=IXWebSocket C++ Server Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/home/ubuntu/connection-ixwebsocket-cpp
ExecStart=/home/ubuntu/connection-ixwebsocket-cpp/dist/linux/app
Restart=always
RestartSec=5

# Standard output and error logging
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
Note: Replace /home/ubuntu/connection-ixwebsocket-cpp with the exact absolute path to your project directory on your VPS. Примечание: Замените /home/ubuntu/connection-ixwebsocket-cpp на точный абсолютный путь к директории вашего проекта на VPS.

2. Enable and Start the Service 2. Включение и запуск службы

Reload the systemd daemon to recognize the new unit file, enable it to launch automatically on boot, and start it immediately: Перезагрузите демон systemd, чтобы зарегистрировать новый файл юнита, разрешите его автоматический запуск при загрузке системы и запустите его немедленно: 

# Reload systemd configuration
sudo systemctl daemon-reload

# Enable service to auto-start on boot
sudo systemctl enable ixwebsocket-server

# Start the service right now
sudo systemctl start ixwebsocket-server

3. Service Management & Verification 3. Управление службой и проверка

Check the active running status of your WebSocket server process: Проверьте текущий статус выполнения процесса вашего WebSocket сервера: 

sudo systemctl status ixwebsocket-server

Common Service Commands: Основные команды управления:

CommandКоманда ActionДействие
sudo systemctl start ixwebsocket-server Starts the server process.Запускает процесс сервера.
sudo systemctl stop ixwebsocket-server Stops the server process.Останавливает процесс сервера.
sudo systemctl restart ixwebsocket-server Restarts the server process.Перезапускает процесс сервера.
sudo journalctl -u ixwebsocket-server -f Streams live logs (std::cout / std::cerr).Выводит логи в реальном времени (std::cout / std::cerr).
Success: Your WebSocket server is now running as a background service and will automatically restart if it crashes or when the VPS reboots. Успех: Ваш WebSocket сервер теперь работает как фоновая служба и будет автоматически перезапускаться в случае сбоя или при перезагрузке VPS.
