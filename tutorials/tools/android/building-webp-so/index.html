Building WebP to .so for Android Сборка WebP в .so для Android

A guide to compiling WebP source code into a shared library (libwebp.so) for Android (arm64-v8a) using CMake. Руководство по компиляции исходного кода WebP в динамическую библиотеку (libwebp.so) для Android (arm64-v8a) с помощью CMake.

If you haven't set up MinGW and CMake on your machine, follow the Если вы еще не настроили MinGW и CMake на своем компьютере, следуйте инструкции: MinGW & CMake Setup Guide Руководство по настройке MinGW и CMake
If you haven't set up your environment (Android SDK, NDK, JDK), follow the Если вы еще не настроили окружение (Android SDK, NDK, JDK), следуйте инструкции: Environment Setup Guide Руководство по настройке окружения

Step 1: Download WebP Source Code Шаг 1: Скачивание исходного кода WebP

Download the latest WebP source archive (.zip or .tar.gz) from the official GitHub tags page: Скачайте последний архив с исходным кодом WebP (.zip или .tar.gz) с официальной страницы тегов GitHub:

Download WebP Releases Скачать релизы WebP

Extract the downloaded archive to a convenient directory on your machine. Распакуйте скачанный архив в удобную директорию на вашем компьютере.

Step 2: Create the Build Script Шаг 2: Создание скрипта сборки

In the root directory of the extracted WebP source folder, create an empty file named build-android-64-bit.bat and paste the following content into it: В корневой директории распакованного исходного кода WebP создайте пустой файл build-android-64-bit.bat и вставьте в него следующее содержимое: 

@echo off
set NDK=H:/AndroidSDK/ndk/28.2.13676358

if not exist build-android-64 mkdir build-android-64
cd build-android-64

:: Clean old cache completely
if exist CMakeCache.txt del CMakeCache.txt
if exist CMakeFiles rmdir /s /q CMakeFiles

cmake .. ^
  -DCMAKE_TOOLCHAIN_FILE=%NDK%/build/cmake/android.toolchain.cmake ^
  -DANDROID_ABI=arm64-v8a ^
  -DANDROID_PLATFORM=android-21 ^
  -DBUILD_SHARED_LIBS=ON ^
  -DWEBP_BUILD_CWEBP=OFF ^
  -DWEBP_BUILD_DWEBP=OFF ^
  -DWEBP_BUILD_GIF2WEBP=OFF ^
  -DWEBP_BUILD_IMG2WEBP=OFF ^
  -DWEBP_BUILD_VWEBP=OFF ^
  -DWEBP_BUILD_WEBPINFO=OFF ^
  -DWEBP_BUILD_WEBPMUX=OFF ^
  -DWEBP_BUILD_ANIM_UTILS=OFF ^
  -DWEBP_BUILD_EXTRAS=OFF ^
  -DWEBP_BUILD_LIBWEBPMUX=ON ^
  -DWEBP_NEAR_LOSSLESS=ON ^
  -DWEBP_ENABLE_SIMD=ON ^
  -DCMAKE_BUILD_TYPE=Release ^
  -DCMAKE_INSTALL_PREFIX=C:/libs/webp-android/arm64-v8a ^
  -G "MinGW Makefiles"

cmake --build . --config Release --target install
Note: Примечание: Make sure to adjust the NDK path and CMAKE_INSTALL_PREFIX according to your local environment paths. Убедитесь, что пути к NDK и CMAKE_INSTALL_PREFIX соответствуют вашему локальному окружению.

Step 3: Run and Compile Шаг 3: Запуск и сборка

Double-click build-android-64-bit.bat or run it via Command Prompt. Once completed, your compiled libwebp.so along with headers will be installed in the output path set by CMAKE_INSTALL_PREFIX. Дважды кликните по build-android-64-bit.bat или запустите его через командную строку. После завершения собранная библиотека libwebp.so вместе с заголовочными файлами будет установлена по пути, указанному в CMAKE_INSTALL_PREFIX.
