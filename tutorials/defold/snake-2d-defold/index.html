2D Snake: Building with Defold 2D Snake: Создание игры на Defold

Learn to build a functional Snake clone using Defold's lightweight component architecture. Научитесь создавать клон игры Snake, используя компонентную архитектуру Defold.

Prerequisites Предварительные требования

Before starting, ensure you have Defold installed. If not, check our setup guide.

Перед началом убедитесь, что у вас установлен Defold. Если нет, ознакомьтесь с нашим руководством по установке.

1. Project Setup 1. Настройка проекта

Create a new 2D project. In Defold, we use Collections to organize our game objects (Snake, Food, Borders).

Создайте новый 2D проект. В Defold мы используем коллекции для организации игровых объектов (Змея, Еда, Границы).

2. The Snake Logic (Lua) 2. Логика змеи (Lua)

Unlike Unity's Update(), Defold uses a tick-based system in update(self, dt). Here is how you handle snake movement:

function update(self, dt)
    self.timer = self.timer + dt
    if self.timer >= self.speed then
        -- Logic: Move head, update tail positions
        local new_head = self.snake[1] + self.dir
        table.insert(self.snake, 1, new_head)
        table.remove(self.snake)
        self.timer = 0
    end
end

3. Input Handling 3. Обработка ввода

Defold uses a dedicated on_input function. This is more efficient than checking keys every frame.

function on_input(self, action_id, action)
    if action.pressed then
        if action_id == hash("up") then self.dir = vmath.vector3(0, 10, 0) end
        -- Add left/right/down logic here
    end
end

4. Collisions 4. Столкновения

Use Defold Collision Objects with group/mask filtering. When the snake head hits food, the engine triggers on_message with a trigger_response.

Используйте Collision Objects с фильтрацией групп. Когда голова змеи касается еды, движок отправляет сообщение trigger_response.
