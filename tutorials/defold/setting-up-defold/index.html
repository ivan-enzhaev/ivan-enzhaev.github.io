Defold Engine: Setup and Deployment Движок Defold: Установка и развертывание

A complete guide to getting started with Defold on Windows and preparing your game for EXE, Web, and Android. Полное руководство по началу работы с Defold на Windows и подготовке игры для EXE, Web и Android.

1. Download & Installation 1. Загрузка и установка

Defold is a portable application. Download the editor from the official website:

Defold — это портативное приложение. Загрузите редактор с официального сайта:

Download Defold Editor

Extract the downloaded ZIP file to any location on your computer and run Defold.exe.

Распакуйте загруженный ZIP-архив в любое место на вашем компьютере и запустите Defold.exe.

2. Creating Your First Project 2. Создание первого проекта

Open the editor and select New Project. Choose the "Empty Project" template to start from scratch.

Откройте редактор и выберите New Project. Выберите шаблон "Empty Project", чтобы начать с чистого листа.

3. Building for Targets (EXE, Wasm, Android) 3. Сборка под целевые платформы (EXE, Wasm, Android)

Defold uses the Project -> Bundle menu to export your game for different platforms:

Defold использует меню Project -> Bundle для экспорта игры под разные платформы:

  • Windows Application (.exe): Select Project -> Bundle -> Microsoft Windows Application.
  • Web (Wasm/HTML5): Select Project -> Bundle -> HTML5 Application.
  • Android: Select Project -> Bundle -> Android Application. (Requires Android SDK/JDK setup)

4. Development Workflow 4. Рабочий процесс

Use Ctrl+B to build and launch your game immediately within the editor for testing.

Используйте Ctrl+B, чтобы собрать и запустить игру прямо в редакторе для тестирования.
