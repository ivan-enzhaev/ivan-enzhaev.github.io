Action Queue & Cutscene System with SFML 3 (C++20) Система очереди действий и кат-сцен на SFML 3 (C++20)

A beginner-friendly guide to implementing the Action / Command Queue Pattern in modern C++ (C++20) using the SFML 3 Graphics and Window API. Learn how to sequence animations, smoothly interpolate transformations (Lerp), and create organic pulsing effects using sine wave trigonometry without complex state machines. Руководство для начинающих по реализации паттерна очереди действий/команд (Action / Command Queue) на современном C++ (C++20) с использованием графического API SFML 3. Узнайте, как выстраивать цепочки анимаций, плавно интерполировать трансформации (Lerp) и создавать органичный эффект пульсации с помощью тригонометрии синуса без громоздких конечных автоматов.

Pattern Overview Обзор паттерна

This code implements an Action Queue / Command Pattern commonly used in game engines (similar to Tweens in Godot/Unity or Actions in Cocos2d) to chain animations and scripted cutscenes sequentially without spaghetti state machines. Этот код реализует паттерн Action Queue / Command, широко применяемый в игровых движках (аналог Tweens в Godot/Unity или Actions в Cocos2d) для последовательного выстраивания анимаций и скриптовых кат-сцен без громоздких конечных автоматов.

Why SFML 3 Renderer? Почему именно рендерер SFML 3?

SFML 3 provides an idiomatic, strongly-typed modern C++20 API. By using SFML's 2D graphics module (sf::RenderWindow, sf::VertexArray, sf::Transform, sf::Angle), we eliminate the manual boilerplate of raw OpenGL shaders, VAO/VBO buffers, and external matrix math libraries while retaining hardware-accelerated performance and clean object-oriented architecture. SFML 3 предоставляет идиоматичный, строго типизированный API современного C++20. Использование 2D-модуля графики SFML (sf::RenderWindow, sf::VertexArray, sf::Transform, sf::Angle) избавляет от необходимости писать шейдеры OpenGL, управлять буферами VAO/VBO и подключать внешние математические библиотеки матриц, сохраняя аппаратное ускорение и чистую объектно-ориентированную архитектуру.

Core Architecture: In-Depth Class Breakdown Основная архитектура: подробный разбор классов

1. enum class ActionStatus

enum class ActionStatus {
    Running,
    Finished
};
  • Purpose:Назначение: A strongly-typed state return for each action. Строго типизированный возврат статуса для каждого действия.
  • Role:Роль: Tells the ActionQueue whether the current action is still running or has completed its work and should be discarded. Сообщает ActionQueue, выполняется ли ещё текущее действие или оно завершило свою работу и должно быть удалено из очереди.

2. class Action (The Abstract Base Class)

class Action {
public:
    virtual ~Action() = default;
    virtual void on_start() {}
    virtual ActionStatus update(float dt) = 0;
};

Purpose:Назначение: The interface / contract representing any timed or progressive task. Базовый интерфейс/контракт, представляющий любую задачу, распределённую по времени.

Key Components: Ключевые компоненты:

  • virtual ~Action() = default;: Ensures that when derived classes held by std::unique_ptr<Action> are deleted, their specific destructors are invoked properly (preventing memory leaks). Гарантирует, что при удалении производных классов, управляемых std::unique_ptr<Action>, корректно вызывается их деструктор (предотвращая утечки памяти).
  • virtual void on_start(): An optional lifecycle hook called only once on the very first frame the action begins executing. This is crucial for capturing initial states (e.g., current angle or color) at runtime rather than when the action is created. Опциональный хук жизненного цикла, вызываемый ровно один раз в самый первый кадр начала выполнения действия. Он необходим для фиксации начального состояния (например, текущего угла или цвета) в рантайме, а не в момент создания объекта.
  • virtual ActionStatus update(float dt) = 0;: Pure virtual function. Every derived action must implement how it progresses over a delta-time step (dt). It returns ActionStatus::Running while active and ActionStatus::Finished when done. Чисто виртуальная функция. Каждое производное действие обязано реализовать изменение своего состояния за дельта-тайм (dt). Возвращает ActionStatus::Running во время работы и ActionStatus::Finished по завершении.

3. class ActionQueue (The Sequencer / Manager)

class ActionQueue {
public:
    void push(std::unique_ptr<Action> action);
    void update(float dt);
    bool is_empty() const;
    void clear();

private:
    std::deque<std::unique_ptr<Action>> queue;
    bool started = false;
};

Purpose:Назначение: Manages a FIFO (First-In, First-Out) sequential pipeline of polymorphic actions. Управляет последовательным конвейером полиморфных действий по принципу FIFO (первым пришел — первым ушел).

Key Mechanisms: Ключевые механизмы:

  • std::deque<std::unique_ptr<Action>>: Holds ownership of the actions. std::unique_ptr guarantees that each action is automatically deleted from memory as soon as it is popped. Владеет действиями. std::unique_ptr гарантирует, что каждый экземпляр действия автоматически удаляется из памяти сразу после извлечения из очереди.
  • push(std::unique_ptr<Action> action): Adds a new action to the back of the queue using std::move. Добавляет новое действие в конец очереди с помощью std::move.
  • update(float dt):
    • Returns immediately if the queue is empty.Немедленно возвращает управление, если очередь пуста.
    • If !started, triggers on_start() on the action at the front of the queue, then sets started = true.Если !started, вызывает on_start() у первого действия в очереди и устанавливает started = true.
    • Calls queue.front()->update(dt).Вызывает queue.front()->update(dt).
    • When update(dt) returns ActionStatus::Finished, it calls queue.pop_front() (deleting the action) and resets started = false, so the next action in line will have its on_start() invoked on the next frame.Когда update(dt) возвращает ActionStatus::Finished, вызывается queue.pop_front() (удаляя действие) и сбрасывается started = false, чтобы у следующего действия в очереди на следующем кадре сработал on_start().
  • is_empty() & clear(): Utility methods to inspect or flush the queue. Вспомогательные методы для проверки на пустоту и полной очистки очереди.

4. struct AppState (The Context / Data Store)

struct AppState {
    // Transformation variables modified by our Action Queue
    float rotationAngle = 0.0f; // in radians
    float scale = 1.0f;
    sf::Color clearColor{31, 31, 38};

    ActionQueue actionQueue;
};
  • Purpose:Назначение: The central data structure holding the state variables (rotationAngle, scale, clearColor) and the ActionQueue itself. Центральная структура данных, хранящая параметры состояния (rotationAngle, scale, clearColor) и саму ActionQueue.
  • Role with Actions:Связь с действиями: A pointer to AppState (AppState*) is passed into each concrete action so the action can directly manipulate the shared animation properties. Указатель на AppState (AppState*) передаётся в каждое конкретное действие, позволяя ему напрямую изменять разделяемые анимируемые параметры.

5. Concrete Action Classes

Each concrete action inherits from Action and implements a specific animation behavior: Каждое конкретное действие наследуется от Action и реализует заданное поведение анимации:

A. RotateAction (Linear Interpolation / Lerp)
  • Constructor:Конструктор: Takes target angle (targetAngleRad) and duration.Принимает целевой угол (targetAngleRad) и длительность duration.
  • on_start(): Reads current state->rotationAngle as startAngle. This ensures smooth continuity even if previous rotations left the object at an arbitrary angle.Запоминает текущий state->rotationAngle как startAngle. Это гарантирует непрерывность, даже если предыдущее вращение завершилось под произвольным углом.
  • update(float dt):
    • Accumulates elapsed time: elapsed += dt.Накапливает прошедшее время: elapsed += dt.
    • Normalizes time t ∈ [0.0, 1.0]: t = min(1.0f, elapsed / duration).Нормализует время t ∈ [0.0, 1.0]: t = min(1.0f, elapsed / duration).
    • Interpolates: state->rotationAngle = startAngle + (target - startAngle) * t.Интерполирует: state->rotationAngle = startAngle + (target - startAngle) * t.
    • Returns Finished once t ≥ 1.0f.Возвращает Finished, как только t ≥ 1.0f.
B. PulseAction (Mathematical / Sinusoidal Wave)
  • Constructor:Конструктор: Takes maxScale and duration.Принимает maxScale и длительность duration.
  • update(float dt):

    Uses the half-period of a sine wave: state->scale = 1.0f + (maxScale - 1.0f) * std::sin(t * 3.14159265f); where t ∈ [0.0, 1.0].Использует полупериод синусоиды: state->scale = 1.0f + (maxScale - 1.0f) * std::sin(t * 3.14159265f); где t ∈ [0.0, 1.0].

    • At t = 0.0: sin(0) = 0.0 → scale = 1.0 (Original sizeИсходный размер)
    • At t = 0.5: sin(π / 2) = 1.0 → scale = maxScale (Peak scaleПиковый масштаб)
    • At t = 1.0: sin(π) = 0.0 → scale = 1.0 (Original sizeИсходный размер)
    Smoothly scales up and down back to original size in a single action. Плавно увеличивает и уменьшает объект обратно до исходного размера в рамках одного действия.
C. FadeColorAction (RGB Vector Interpolation)
  • Constructor:Конструктор: Takes target sf::Color and duration.Принимает целевой sf::Color и длительность duration.
  • on_start(): Captures current background color: startColor = state->clearColor.Фиксирует текущий цвет фона: startColor = state->clearColor.
  • update(float dt): Simultaneously lerps each of the red, green, and blue components of sf::Color from starting to target values over duration.Синхронно интерполирует компоненты красного, зелёного и синего цветов sf::Color от начального к целевому за время duration.

How They Tie Together in the Game Loop Связка компонентов в игровом цикле 

[setupCutscene(state)]
    Pushes: RotateAction -> PulseAction -> FadeColorAction -> RotateAction -> FadeColorAction

[Every Frame in while (window.isOpen())]
    1. dt = clock.restart().asSeconds()
    2. state.actionQueue.update(dt)
       ├── Frame 1 of an Action: calls on_start()
       ├── Every Frame: calls update(dt) -> modifies state.rotationAngle, scale, or clearColor
       └── Last Frame: returns Finished -> ActionQueue pops it -> moves to next
    3. If actionQueue.is_empty(), setupCutscene(&state) is called again to loop.
    4. window.clear(state.clearColor)
    5. Apply sf::Transform (translate to center, rotate, scale) -> window.draw(triangle, transform)
    6. window.display()

Architectural Highlights Ключевые преимущества архитектуры

  • Separation of Concerns:Разделение ответственности: Rendering logic doesn't care how properties change; it just transforms and draws whatever values are stored in AppState. Логика отрисовки не заботится о том, как меняются параметры; она просто трансформирует и рисует актуальные значения из AppState.
  • Extensibility:Расширяемость: Adding new actions (e.g., TranslateAction, WaitAction, PlaySoundAction) requires only subclassing Action without altering ActionQueue or rendering code. Добавление новых действий (например, TranslateAction, WaitAction, PlaySoundAction) требует лишь создания нового наследника Action без изменения ActionQueue или кода рендеринга.
  • Safe Memory Management:Безопасное управление памятью: Using std::unique_ptr with std::deque eliminates manual new/delete calls for dynamic action instances. Использование std::unique_ptr вместе с std::deque полностью исключает ручные вызовы new/delete для динамических экземпляров действий.

1. File Contents for src/main.cpp (SFML 3) 1. Содержимое файла src/main.cpp (SFML 3) 

#include <SFML/Graphics.hpp>

#include <vector>
#include <deque>
#include <memory>
#include <cmath>
#include <algorithm>

// ============================================================================
// Action / Command Queue System
// ============================================================================

enum class ActionStatus {
    Running,
    Finished
};

class Action {
public:
    virtual ~Action() = default;
    virtual void on_start() {}
    virtual ActionStatus update(float dt) = 0;
};

class ActionQueue {
public:
    void push(std::unique_ptr<Action> action) {
        queue.push_back(std::move(action));
    }

    void update(float dt) {
        if (queue.empty()) return;

        if (!started) {
            queue.front()->on_start();
            started = true;
        }

        if (queue.front()->update(dt) == ActionStatus::Finished) {
            queue.pop_front();
            started = false; // Next action will call on_start() on next frame
        }
    }

    bool is_empty() const { return queue.empty(); }
    void clear() { queue.clear(); started = false; }

private:
    std::deque<std::unique_ptr<Action>> queue;
    bool started = false;
};

// ============================================================================
// Application State
// ============================================================================

struct AppState {
    // Transformation variables modified by our Action Queue
    float rotationAngle = 0.0f; // in radians
    float scale = 1.0f;
    sf::Color clearColor{31, 31, 38};

    ActionQueue actionQueue;
};

// ============================================================================
// Concrete Cutscene Actions
// ============================================================================

class RotateAction : public Action {
public:
    RotateAction(AppState* state, float targetAngleRad, float duration)
        : state(state), target(targetAngleRad), duration(duration) {}

    void on_start() override {
        startAngle = state->rotationAngle;
        elapsed = 0.0f;
    }

    ActionStatus update(float dt) override {
        elapsed += dt;
        float t = (duration > 0.0f) ? std::min(1.0f, elapsed / duration) : 1.0f;
        state->rotationAngle = startAngle + (target - startAngle) * t;
        return (t >= 1.0f) ? ActionStatus::Finished : ActionStatus::Running;
    }

private:
    AppState* state;
    float startAngle = 0.0f;
    float target;
    float duration;
    float elapsed = 0.0f;
};

class PulseAction : public Action {
public:
    PulseAction(AppState* state, float maxScale, float duration)
        : state(state), maxScale(maxScale), duration(duration) {}

    ActionStatus update(float dt) override {
        elapsed += dt;
        float t = std::min(1.0f, elapsed / duration);
        state->scale = 1.0f + (maxScale - 1.0f) * std::sin(t * 3.14159265f);
        return (t >= 1.0f) ? ActionStatus::Finished : ActionStatus::Running;
    }

private:
    AppState* state;
    float maxScale;
    float duration;
    float elapsed = 0.0f;
};

class FadeColorAction : public Action {
public:
    FadeColorAction(AppState* state, sf::Color targetColor, float duration)
        : state(state), target(targetColor), duration(duration) {}

    void on_start() override {
        start = state->clearColor;
        elapsed = 0.0f;
    }

    ActionStatus update(float dt) override {
        elapsed += dt;
        float t = (duration > 0.0f) ? std::min(1.0f, elapsed / duration) : 1.0f;

        auto lerp = [](uint8_t a, uint8_t b, float factor) -> uint8_t {
            return static_cast<uint8_t>(static_cast<float>(a) + (static_cast<float>(b) - static_cast<float>(a)) * factor);
        };

        state->clearColor = sf::Color(
            lerp(start.r, target.r, t),
            lerp(start.g, target.g, t),
            lerp(start.b, target.b, t)
        );

        return (t >= 1.0f) ? ActionStatus::Finished : ActionStatus::Running;
    }

private:
    AppState* state;
    sf::Color start;
    sf::Color target;
    float duration;
    float elapsed = 0.0f;
};

static void setupCutscene(AppState* state) {
    // Step 1: Rotate 360 degrees (2*PI) in 1.5 seconds
    state->actionQueue.push(std::make_unique<RotateAction>(state, 6.2831853f, 1.5f));

    // Step 2: Pulse scale up to 1.8x and back in 1.0 second
    state->actionQueue.push(std::make_unique<PulseAction>(state, 1.8f, 1.0f));

    // Step 3: Shift background to vibrant purple over 1.0 second
    state->actionQueue.push(std::make_unique<FadeColorAction>(state, sf::Color(89, 25, 115), 1.0f));

    // Step 4: Rotate back to 0 in 1.2 seconds
    state->actionQueue.push(std::make_unique<RotateAction>(state, 0.0f, 1.2f));

    // Step 5: Shift background back to dark slate in 1.0 second
    state->actionQueue.push(std::make_unique<FadeColorAction>(state, sf::Color(31, 31, 38), 1.0f));
}

// ============================================================================
// Main Application Loop
// ============================================================================

int main() {
    sf::RenderWindow window(sf::VideoMode({800u, 600u}), "Action Queue Cutscene Demo (SFML 3)");
    window.setFramerateLimit(60);

    AppState state;
    setupCutscene(&state);

    // Setup an RGB triangle centered around its local origin (0, 0)
    sf::VertexArray triangle(sf::PrimitiveType::Triangles, 3);
    triangle[0].position = sf::Vector2f{  0.0f, -120.0f}; // Top vertex
    triangle[0].color    = sf::Color{255, 51, 51};        // Red

    triangle[1].position = sf::Vector2f{-100.0f,   80.0f}; // Bottom-left vertex
    triangle[1].color    = sf::Color{ 51, 255, 51};       // Green

    triangle[2].position = sf::Vector2f{ 100.0f,   80.0f}; // Bottom-right vertex
    triangle[2].color    = sf::Color{ 51, 102, 255};      // Blue

    sf::Clock clock;

    while (window.isOpen()) {
        while (const std::optional event = window.pollEvent()) {
            if (event->is<sf::Event::Closed>()) {
                window.close();
            }
        }

        float dt = clock.restart().asSeconds();

        // 1. Advance the Action Queue
        state.actionQueue.update(dt);

        // If the sequence finished, loop it again
        if (state.actionQueue.is_empty()) {
            setupCutscene(&state);
        }

        // 2. Render Frame
        window.clear(state.clearColor);

        // Compute 2D transformation: translate to center, apply rotation and scale
        sf::Transform transform;
        transform.translate(sf::Vector2f{400.0f, 300.0f});
        transform.rotate(sf::radians(state.rotationAngle));
        transform.scale(sf::Vector2f{state.scale, state.scale});

        window.draw(triangle, transform);
        window.display();
    }

    return 0;
}
