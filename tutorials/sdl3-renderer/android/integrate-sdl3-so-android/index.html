Integrating compiled libSDL3.so on Android Интеграция собранной библиотеки libSDL3.so на Android

A step-by-step guide to creating a test application, linking your compiled libSDL3.so, building an APK, and running it on an Android device. Пошаговое руководство по созданию тестового приложения, связыванию собранной библиотеки libSDL3.so, сборке APK и запуску на Android-устройстве.

If you haven't built the core SDL3 library yet, follow the Если вы еще не собрали основную библиотеку SDL3, следуйте инструкции: Building SDL3 shared library for Android Сборка динамической библиотеки SDL3 для Android

Step 1: Project Setup Шаг 1: Настройка структуры проекта

Create a new empty directory on your machine for your project (e.g., sdl3-android-app). Создайте новую пустую директорию на вашем компьютере для проекта (например, sdl3-android-app).

Copy the android-project directory from the official SDL3 repository into your new folder: Скопируйте директорию android-project из официального репозитория SDL3 в созданную папку:

SDL3 android-project Source Исходники android-project SDL3

Next, delete the unneeded native source template folder: Затем удалите ненужную папку с шаблоном нативных исходников:

  • android-project\app\jni

Step 2: Create CMakeLists.txt Шаг 2: Создание CMakeLists.txt

In the root of your created project folder (outside android-project), create a CMakeLists.txt file: В корне созданной папки проекта (рядом с android-project) создайте файл CMakeLists.txt: 

cmake_minimum_required(VERSION 3.21)
project(sdl3-android-app)

set(CMAKE_C_STANDARD 17)
set(CMAKE_C_STANDARD_REQUIRED ON)

add_library(SDL3 SHARED IMPORTED)
set_target_properties(SDL3 PROPERTIES
    IMPORTED_LOCATION "C:/libs/sdl3-android/arm64-v8a/lib/libSDL3.so"
)

add_library(app SHARED src/main.c)

target_include_directories(app PRIVATE "C:/libs/sdl3-android/arm64-v8a/include")

target_link_libraries(app PRIVATE SDL3)

Step 3: Create the C Source File Шаг 3: Создание исходного файла C

In the root directory, create a folder named src, and inside it, create a file named main.c: В корневой директории создайте папку src, а внутри нее — файл main.c: 

#define SDL_MAIN_USE_CALLBACKS 1 // Use callback functions instead of main()

#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>

// We will use this renderer to draw into this window every frame
static SDL_Window *window = NULL;
static SDL_Renderer *renderer = NULL;

// This function runs once at startup
SDL_AppResult SDL_AppInit(void **appstate, int argc, char *argv[])
{
    if (!SDL_Init(SDL_INIT_VIDEO))
    {
        SDL_Log("Couldn't initialize SDL: %s", SDL_GetError());
        return SDL_APP_FAILURE;
    }

    if (!SDL_CreateWindowAndRenderer("SDL3 Rectangles", 380, 380, 0, &window, &renderer))
    {
        SDL_Log("Couldn't create window/renderer: %s", SDL_GetError());
        return SDL_APP_FAILURE;
    }

    // Enable VSync (1 = sync with every refresh)
    if (!SDL_SetRenderVSync(renderer, 1))
    {
        SDL_Log("Failed to enable VSync: %s", SDL_GetError());
    }

    return SDL_APP_CONTINUE; // Continue program execution!
}

// This function runs whenever a new event occurs (mouse input, key presses, etc.)
SDL_AppResult SDL_AppEvent(void *appstate, SDL_Event *event)
{
    if (event->type == SDL_EVENT_QUIT)
    {
        return SDL_APP_SUCCESS; // Terminate the program, reporting success to the OS
    }
    return SDL_APP_CONTINUE; // Continue program execution!
}

// This function runs once per frame and is the heart of the program
SDL_AppResult SDL_AppIterate(void *appstate)
{
    SDL_SetRenderDrawColor(renderer, 38, 43, 51, 255);

    // Clear the window with the draw color
    SDL_RenderClear(renderer);

    // Rectangle 1 (Red)
    SDL_FRect rect1 = { 50.0f, 150.0f, 100.0f, 50.0f };
    SDL_SetRenderDrawColor(renderer, 255, 0, 0, 255);
    SDL_RenderFillRect(renderer, &rect1);

    // Rectangle 2 (Green)
    SDL_FRect rect2 = { 200.0f, 150.0f, 100.0f, 50.0f };
    SDL_SetRenderDrawColor(renderer, 0, 255, 0, 255);
    SDL_RenderFillRect(renderer, &rect2);

    // Rectangle 3 (Blue)
    SDL_FRect rect3 = { 125.0f, 50.0f, 100.0f, 50.0f };
    SDL_SetRenderDrawColor(renderer, 0, 0, 255, 255);
    SDL_RenderFillRect(renderer, &rect3);

    // Present the freshly cleared result to the screen
    SDL_RenderPresent(renderer);

    return SDL_APP_CONTINUE; // Continue program execution!
}

// This function runs once upon shutdown
void SDL_AppQuit(void *appstate, SDL_AppResult result)
{
    // SDL will clean up the window and renderer for us
}

Step 4: Configure Gradle and Android Settings Шаг 4: Настройка Gradle и параметров Android

1. Replace the content of android-project/app/build.gradle with: 1. Замените содержимое файла android-project/app/build.gradle следующим кодом: 

plugins {
    id 'com.android.application'
}

android {
    namespace "com.example.myapp"
    compileSdkVersion 35

    defaultConfig {
        applicationId 'com.example.myapp'
        minSdkVersion 21
        targetSdkVersion 35
        versionCode 1
        versionName '1.0'

        externalNativeBuild {
            cmake {
                arguments '-DANDROID_STL=c++_shared'
                abiFilters 'arm64-v8a'
            }
        }
    }

    externalNativeBuild {
        cmake {
            path '../../CMakeLists.txt'
        }
    }

    buildTypes {
        release {
            minifyEnabled false
            proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
        }
    }

    compileOptions {
        sourceCompatibility JavaVersion.VERSION_1_8
        targetCompatibility JavaVersion.VERSION_1_8
    }

    buildFeatures {
        prefab false
    }
}

dependencies {
    implementation 'androidx.appcompat:appcompat:1.5.1'
}

2. Create a custom Java activity at path android-project\app\src\main\java\com\example\myapp\MyActivity.java: 2. Создайте пользовательский Java-класс по пути android-project\app\src\main\java\com\example\myapp\MyActivity.java: 

package com.example.myapp;

import org.libsdl.app.SDLActivity;

public class MyActivity extends SDLActivity {
    protected String[] getLibraries() {
        return new String[] { "app" };
    }
}

3. In android-project\app\src\main\AndroidManifest.xml, update the activity tag to point to your new package name: 3. В файле android-project\app\src\main\AndroidManifest.xml измените строку объявления activity: 

<activity android:name="com.example.myapp.MyActivity"

4. Open android-project\gradle.properties and append this line: 4. Откройте android-project\gradle.properties и добавьте следующую строку: 

android.useAndroidX=true

Step 5: Create Build and Install Scripts Шаг 5: Создание скриптов сборки и установки

In the root folder of your project, create two helper batch files to compile and install the application automatically. В корневой папке проекта создайте два вспомогательных bat-файла для автоматической сборки и установки приложения.

build-apk.bat

cd android-project
call gradlew assembleDebug
cd ..

install-apk.bat

cd android-project\app\build\outputs\apk\debug
call adb install -r -d app-debug.apk
cd ..\..\..\..\..\..

Step 6: Build, Deploy, and Debug Шаг 6: Сборка, развертывание и отладка

Enable Developer Options and USB Debugging on your Android device, then connect it to your computer via USB. Включите Режим разработчика и Отладку по USB на вашем Android-устройстве, после чего подключите его к компьютеру через USB-кабель.

Execute the batch scripts in your Command Prompt (CMD): Выполните батч-скрипты в командной строке (CMD): 

build-apk
install-apk

Useful ADB Commands: Полезные команды ADB:

Uninstall the application from the device: Удаление приложения с устройства: 

adb uninstall com.example.myapp

Clear logs and view real-time runtime errors: Очистка логов и просмотр ошибок в реальном времени: 

adb logcat -c
adb logcat -d AndroidRuntime:E DEBUG:E *:S
Tip: Совет: You can open the android-project directory directly in Android Studio to set breakpoints and debug your code in step-by-step mode! Вы можете открыть папку android-project прямо в Android Studio, чтобы ставить точки останова (breakpoints) и отлаживать приложение в пошаговом режиме!
