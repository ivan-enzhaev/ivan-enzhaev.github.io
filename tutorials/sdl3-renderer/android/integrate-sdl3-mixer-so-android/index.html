Integrating compiled libSDL3_mixer.so on Android Интеграция собранной библиотеки libSDL3_mixer.so на Android

A step-by-step guide to adding SDL3_mixer support to your Android project, handling asset copying via CMake, and playing audio on mobile devices. Пошаговое руководство по добавлению поддержки SDL3_mixer в ваш Android-проект, автоматической копировании ассетов через CMake и воспроизведению аудио на мобильных устройствах.

Before starting this guide, make sure you have completed the foundational tutorials: Перед началом работы убедитесь, что вы выполнили предыдущие руководства:
  • Integrating compiled libSDL3.so on Android Интеграция собранной библиотеки libSDL3.so на Android
  • Building SDL3_mixer to .so for Android Сборка SDL3_mixer в .so для Android

Open CMakeLists.txt in the root directory and update it to link both SDL3 and SDL3_mixer libraries: Откройте CMakeLists.txt в корне проекта и обновите его для связывания обоих библиотек (SDL3 и SDL3_mixer):

Step 3: Configure Gradle Source Sets Шаг 3: Настройка Source Sets в Gradle

Open android-project/app/build.gradle and set the sourceSets block inside android { ... }. This instructs Gradle to bundle assets directly from the project's root assets folder: Откройте android-project/app/build.gradle и настройте блок sourceSets внутри android { ... }. Это укажет Gradle упаковывать ассеты напрямую из корневой папки assets: 

android {
    namespace "com.example.myapp"
    compileSdkVersion 35

    defaultConfig {
        // ...
    }

    // Direct Gradle to fetch assets straight from the root project folder
    sourceSets {
        main {
            assets.srcDirs = ['../../assets']
        }
    }

    externalNativeBuild {
        cmake {
            path '../../CMakeLists.txt'
        }
    }
}

Step 4: Setup Project Assets Шаг 4: Настройка ресурсов (Assets)

1. Create an assets/audio directory in your project's root folder. 1. Создайте директорию assets/audio в корневой папке проекта.

2. Download the required test audio files from OpenGameArt.org and place them in assets/audio/: 2. Скачайте необходимые тестовые аудиофайлы с OpenGameArt.org и поместите их в assets/audio/:

  • song18.mp3 – Crystal Cave (Background Music) Crystal Cave (Фоновая музыка)
  • qubodup-crash.ogg – Crash Collision (Sound Effect) Crash Collision (Звуковой эффект)
  • spell3.wav – Spell 3 (Sound Effect) Spell 3 (Звуковой эффект)
