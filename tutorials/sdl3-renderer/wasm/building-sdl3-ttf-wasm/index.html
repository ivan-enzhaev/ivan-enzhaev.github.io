Building SDL3_ttf for Wasm Сборка SDL3_ttf для Wasm

Important: Before building SDL3_ttf, you must have SDL3 already compiled for WebAssembly. Follow the Building SDL3 for Wasm guide. Важно: Перед сборкой SDL3_ttf у вас уже должна быть скомпилированная версия SDL3 для WebAssembly. Следуйте руководству по сборке SDL3 для Wasm.

1. Building FreeType 1. Сборка FreeType

SDL3_ttf depends on FreeType. We need to build it for Wasm first. SDL3_ttf зависит от FreeType. Сначала нам нужно собрать его для Wasm.

  • Download FreeType 2.14.3 from the official repository. Скачайте FreeType 2.14.3 с официального репозитория.
  • Unzip it to C:/libs. Распакуйте в C:/libs.
  • Open CMD as Administrator and navigate to the folder: Откройте CMD от имени администратора и перейдите в папку:
  • Run this command to generate the build files: Запустите эту команду для генерации файлов сборки: 
    emcmake cmake -S . -B dist -DCMAKE_INSTALL_PREFIX="C:/libs/freetype-2.14.3-wasm" -DCMAKE_BUILD_TYPE=Release
    Note: CMAKE_INSTALL_PREFIX defines the directory where the compiled libraries and headers will be placed after installation. Примечание: CMAKE_INSTALL_PREFIX определяет каталог, в который будут помещены скомпилированные библиотеки и заголовочные файлы после установки.
  • Compile the source code: Скомпилируйте исходный код: 
    cmake --build dist -j8
  • Install the headers and libraries to the specified prefix: Установите заголовочные файлы и библиотеки по указанному пути: 
    cmake --install dist

2. Building SDL3_ttf 2. Сборка SDL3_ttf

  • Download SDL3_ttf 3.2.2 source from the official repository. Скачайте исходники SDL3_ttf 3.2.2 с the official repository.
  • Unzip it to C:/libs. Распакуйте в C:/libs.
  • Create a file named config-wasm.bat inside this folder with the following content: Создайте файл config-wasm.bat внутри этой папки со следующим содержимым: 
    emcmake cmake -S . -B dist ^
  -DCMAKE_INSTALL_PREFIX=C:/libs/SDL3_ttf-devel-3.2.2-wasm ^
  -DSDL3_DIR=C:/libs/SDL3-devel-3.4.10-wasm/lib/cmake/SDL3 ^
  -DFREETYPE_INCLUDE_DIR_freetype2=C:/libs/freetype-2.14.3-wasm/include ^
  -DFREETYPE_INCLUDE_DIR_ft2build=C:/libs/freetype-2.14.3-wasm/include/freetype2 ^
  -DFREETYPE_LIBRARY_DEBUG=C:/libs/freetype-2.14.3-wasm/lib/libfreetype.a ^
  -DFREETYPE_LIBRARY_RELEASE=C:/libs/freetype-2.14.3-wasm/lib/libfreetype.a ^
  -DCMAKE_BUILD_TYPE=Release ^
  -DSDLTTF_SAMPLES=OFF
  • Open CMD as Administrator and navigate to the folder: Откройте CMD от имени администратора и перейдите в папку:
  • Run the config-wasm.bat script to generate the build files: Запустите скрипт config-wasm.bat для генерации файлов сборки: 
    config-wasm
  • Compile the source code: Скомпилируйте исходный код: 
    cmake --build dist -j8
  • Install the headers and libraries to the specified prefix: Установите заголовочные файлы и библиотеки по указанному пути: 
    cmake --install dist

3. Pre-compiled Build 3. Готовая сборка

If you prefer to skip the compilation process, you can download the SDL3_ttf-devel-3.2.2-wasm and freetype-2.14.3-wasm.zip packages directly: Если вы предпочитаете пропустить процесс компиляции, вы можете скачать пакеты SDL3_ttf-devel-3.2.2-wasm и freetype-2.14.3-wasm.zip напрямую:

Download SDL3_image-devel-3.2.2-wasm Скачать SDL3_image-devel-3.2.2-wasm

Download freetype-2.14.3-wasm.zip Скачать freetype-2.14.3-wasm.zip

Important: To ensure binary compatibility, you must use Emscripten SDK 4.0.15 when using this pre-compiled build. Using a different version may lead to linker errors or runtime issues. Важно: Для обеспечения бинарной совместимости вы обязаны использовать Emscripten SDK 4.0.15 при использовании этой предварительно скомпилированной сборки. Использование другой версии может привести к ошибкам компоновки или проблемам во время выполнения.
