Building SDL3_mixer for Wasm Сборка SDL3_mixer для Wasm

1. Preparation 1. Подготовка

  • Important: Before building SDL3_mixer, you must have SDL3 already compiled for WebAssembly. Follow this guide: Building SDL3 for Wasm. Важно: Перед сборкой SDL3_mixer у вас уже должна быть скомпилированная версия SDL3 для WebAssembly. Следуйте этому руководству: Сборка SDL3 для Wasm.
  • Download the SDL3_mixer 3.2.4.zip (source Code) from the official GitHub releases: Скачайте SDL3_mixer 3.2.4 (исходный код) с официальных релизов GitHub:
  • Extract it to a folder (e.g., C:/libs). Распакуйте архив в папку (например, C:/libs).
  • Open CMD as Administrator and navigate to the SDL3_mixer-3.2.4 folder: Откройте CMD от имени администратора и перейдите в папку SDL3_mixer-3.2.4:

2. Configure 2. Конфигурация

Run this command to generate the build files. Note that we provide the path to our previously built SDL3 Wasm library via -DSDL3_DIR: Запустите эту команду для генерации файлов сборки. Обратите внимание, что мы указываем путь к ранее собранной библиотеке SDL3 Wasm через -DSDL3_DIR: 

emcmake cmake -S . -B dist -DCMAKE_INSTALL_PREFIX="C:/libs/SDL3_mixer-devel-3.2.4-wasm" -DSDL3_DIR="C:/libs/SDL3-devel-3.4.10-wasm/lib/cmake/SDL3" -DCMAKE_BUILD_TYPE=Release

3. Build & Install 3. Сборка и установка

Compile the source code: Скомпилируйте исходный код: 

cmake --build dist -j8

Install the headers and libraries to the specified prefix: Установите заголовочные файлы и библиотеки по указанному пути: 

cmake --install dist
Success!Успех!
You now have a Wasm-compatible SDL3_mixer build in C:/libs/SDL3_mixer-devel-3.2.4-wasm. Add this to your project's CMake: Теперь у вас есть сборка SDL3_mixer для Wasm в C:/libs/SDL3_mixer-devel-3.2.4-wasm. Добавьте это в CMake вашего проекта:

-DSDL3_mixer_DIR=C:/libs/SDL3_mixer-devel-3.2.4-wasm/lib/cmake/SDL3_mixer

3. Pre-compiled Build 3. Готовая сборка

If you prefer to skip the compilation process, you can download the SDL3_ttf-devel-3.2.2-wasm package directly: Если вы предпочитаете пропустить процесс компиляции, вы можете скачать пакет SDL3_ttf-devel-3.2.2-wasm напрямую:

Download SDL3_image-devel-3.2.2-wasm Скачать SDL3_image-devel-3.2.2-wasm

Important: To ensure binary compatibility, you must use Emscripten SDK 4.0.15 when using this pre-compiled build. Using a different version may lead to linker errors or runtime issues. Важно: Для обеспечения бинарной совместимости вы обязаны использовать Emscripten SDK 4.0.15 при использовании этой предварительно скомпилированной сборки. Использование другой версии может привести к ошибкам компоновки или проблемам во время выполнения.
